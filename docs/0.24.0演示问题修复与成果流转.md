# 0.24.0 演示问题修复与成果流转

右上角新增“继续当前任务”。在对话、文案、图片、视频或一站式创作中切换到资料页面后，可以直接返回；入口按登录账号分别保存。

对话中的“过程与实时输出”默认折叠。展开后可看程序实际执行阶段和逐步收到的回复草稿。服务没有返回流式数据时会如实说明；这里不展示模型内部推理。

## 工作成果怎样进入对应功能

现有文本模型先把请求归类为程序允许的类型，服务端再校验目标、权限和版本，执行对应流程。模型回复“已保存”不能代替程序写入成功。

| 成果 | 确认与保存方式 | 查看位置 |
| --- | --- | --- |
| IP 定位 | 整理成候选，明确新增或更新目标；用户核对或微调后确认写入 | 我的 IP |
| 选题 | 整理成候选，可筛选和修改；确认后加入选题库，重复确认不重复新增 | 选题库 |
| 公众号等文案 | 按平台独立保存草稿和版本，可继续编辑；导出不等于发布 | 当前对话的工作成果 |
| 图片、视频 | 先给生成方案，用户核对模型、内容和费用后确认生成 | 当前成果、作品与素材 |

新增 IP 可以参考原 IP 的定位，但参考角色不等于更新目标。历史候选没有明确写入方式时，应使用“重新整理为新增 IP”或明确选择更新目标，核对新候选后确认。

选题可参考本机已收集的真实资料和热榜。当前对话不具备任意网络搜索工具；没有实际抓取原文时，不能声称已联网核实。候选与已确认选题分开保存。

Jev 是用于分类、评分和路由的决策模型，可以作为未来路由层的候选。本轮修复不接入额外模型；写入目标、版本检查、确认和幂等仍由程序负责。[官方文档](https://docs.typesafe.ai/introduction)

## 文章配图与版本恢复

在正文点击插入位置后，选择“插入图片”或“AI 生成新配图”。窗口保留原位置；配图提示词依据插入段落和邻近文字，用户可添加想法、采用 AI 建议并继续修改。确认生成前不会提交图片生成请求。

选中的图片会显示选择状态，插入后显示实际图片与反馈。异步生成期间如果正文已经变化，系统保留图片并要求重新选择位置，避免静默插到错误段落。

正文改动暂存本机。程序自身保存或仅修改其他元数据时会同步版本；真实外部修改则显示版本比较，并允许保留本机内容或采用已保存内容。错误提供定位或恢复入口，重复同类提示只保留一条。

## 热榜和搜索

热榜按平台分别更新，遇到公共服务限流会尝试有界备用来源。界面区分获取时间、上游榜单时间、缓存和失败保留的历史榜。上游未提供榜单时间时明确标明，不能将抓取时间当成新闻发生时间。

全局搜索只返回匹配的记录，标题匹配优先；少量相关词匹配会明确说明。关联的草稿、任务与素材按关联编号合并，输入新关键词后过期响应不会覆盖新结果。可先预览所选记录，再回到原稿或对应页面。

## 验证边界

功能回归使用隔离数据库和明确标注的测试模型，验证程序实际保存、界面和请求流程；真实热榜来源另外检查。安装版验收读取既有账号与成果，不自动确认用户的历史 IP 候选，也不提交新的付费图片、视频或文本生成。

安装包未商业签名。升级应保留用户数据库、资料、配置和登录状态；确认新版本安装可用后，仅清理旧版本及重复安装包。
