# 梯见创作平台 V2：功能边界与页面设计评审稿

日期：2026-09-21。状态：设计建议，等待业务评审和真实 API 验证；不是开发验收或供应商采购结论。本稿不改变现有软件、配置及历史资料。V1 三张图片继续作为视觉参考，不再作为功能结构依据。

## 1. 本轮确定的产品边界

- 面向电梯企业、经销商和合作方的一站式素材创作；平台维护行业方法和模板，用户提供自己的事实与素材。
- 文本复用现有模型接入。图片、视频、音频、数字人、媒体处理、对标获取走 API。优先闭环，不研发免费抓取或自建生成模型。
- 不做自动知识提炼、夜间整理、跨任务个人记忆。保留显式维护的品牌、IP、产品资料和用户选定的本次参考。
- 功能位置先明确；暂不做的功能列入规划，不能挂到错误模块，更不能显示可执行按钮冒充已接入。
- 网站有功能不等于 API 开放同样能力。公开接口有参数也不等于指定套餐、地区和实际账号已经可用。

## 2. 页面拆分标准

任务目的、核心输入、输出对象或等待生命周期不同，应有独立页面。仅字体、音量、配色等选项不同，留在原页分组。后台上传、查询任务等接口不单独变成用户工具。

独立页面应能独立打开、保存草稿、恢复进度和查看历史；不等于在首页放满入口，也不等于重写所有公共组件。

## 3. 信息架构

```text
创作首页

  文案创作
  图片创作
  AI 视频
  数字人
  音频
  视频合成

发现与研究
  灵感与对标

  我的作品
  我的素材
  品牌与 IP

底部：生成记录、账户与设置
```

左栏只显示这些稳定模块。选中模块后，主区域顶部显示该模块的二级页面导航；不同时铺开所有子功能。首页仅推荐常用工具、继续创作、可实际复用的模板，以及“查看全部工具”。

### 3.1 各模块的二级页面

| 模块 | 首轮应定义的页面 | 预留位置，暂不承诺开发 |
|---|---|---|
| 文案创作 | 通用文案、公众号文章、小红书图文文案、口播脚本 | 长期内容排期、批量营销活动 |
| 图片创作 | AI 生图、图片修改、海报/封面制作 | 多页图文排版、产品图专项工作流 |
| AI 视频 | 文字生成视频、图片生成视频 | 首尾帧控制、参考视频生成、视频续写 |
| 数字人 | 文字口播、音频口播、照片说话、形象库、创建形象 | 双人播客、产品互动、唱歌、PPT 讲解 |
| 音频 | 文本配音、声音库、创建声音 | 变声、降噪、音乐/音效创作 |
| 视频合成 | 素材成片 | 自动粗剪、复杂多轨、单独的视频翻译工具 |
| 灵感与对标 | 单篇研究、对标账号、行业动态、收藏选题 | 商机情报专题；招投标线索不强制进入内容改写 |
| 我的作品 | 全部作品、作品详情及版本 | 团队审批、批量分发 |
| 我的素材 | 上传文件、可用于本次创作的公共素材 | 高级资产协作 |
| 品牌与 IP | 品牌资料、创作身份、AI 定位、身份详情 | 多品牌协作高级权限 |

表中首轮定义不表示同时开发完成。每个工具必须独立标记：优先接入、文档已核对待实测、计划预留。对外产品只开放完成验证的工具。

## 4. 三种视频相关能力的边界

| 模块 | 用户意图 | 主要输入 | 主要输出 |
|---|---|---|---|
| AI 视频 | 生成新的镜头或片段 | 画面描述、参考图片/视频、模型支持的生成设置 | 新生成的视频片段 |
| 数字人 | 让人物讲述或表演 | 可用形象或人物照片、文稿/驱动音频 | 数字人作品 |
| 视频合成 | 把已有内容做成成片 | 已有视频、照片、配音、字幕、片段顺序 | 可交付完整视频 |

三者是并列工具。输出可以互相传递，但不把数字人放进 AI 视频的选项，也不把素材合成叫成文生视频。

## 5. 数字人页面设计

### 5.1 文字口播

目的：用文字让已存在的数字人说话。

```text
数字人 / 文字口播                           草稿已保存
[文字口播] [音频口播] [照片说话] [形象库]

为：安心电梯    创作身份：老林说电梯（用于辅助写稿）

左侧：输入及必要设置                  右侧：预览与本次版本
口播文稿                            生成前：形象/布局示意
粘贴 / 从作品选择 / AI帮写            生成后：实际视频播放器
形象：选择已有形象 / 创建形象          版本与生成状态
声音：选择已有声音 / 创建声音          下载 / 继续包装
样式：基础口播 / 可用模板
字幕：仅在当前方式支持时提供
更多设置：当前接口支持的选项

消耗说明                         [生成口播视频]
```

规则：手工文稿是本次权威输入；选择 IP 不自动改写已输入内容。辅助写稿才使用 IP 与参考资料。切换形象不清空文稿；换模板只重置不兼容选项并明确提示。基础口播和模板包装可以是同页样式选项，只有已验证的组合能被选择。

试听必须是真实音频；未实现精确试听复用时，应明确是声音样例，不能把样例当成整段文稿试听。供应商若对试听计费，不能标免费。

### 5.2 音频口播

目的：让数字人按已经存在的音频发声；保留原音频的声音、节奏和表达。

```text
数字人 / 音频口播

左侧                              右侧
上传音频 / 从我的作品选择            形象示意 / 实际视频
音频播放器、时长、文件状态            本次版本与结果
选择数字人形象
更多设置：仅支持的驱动设置

消耗说明                         [生成口播视频]
```

不显示音色选择、声音克隆必填项或原生文稿编辑框。转写出来的文字可以作为校对资料，但修改它不会改变原音频。若用户要换声音，先去音频工具生成新的音频，再返回继续。

不得默认把文字口播的全部字幕和模板参数搬过来。当前驱动接口不支持的字幕包装可在后续视频合成中处理，相关服务未接入时不开放按钮。

### 5.3 照片说话

目的：从人物照片直接创作一条说话视频。与用产品照片生成运动镜头不是同一工具。

页面输入：人物照片、要说的文字、可用声音、经过验证的生成选项；输出一条视频。首轮按已公开、已验证的输入组合设计，不假定支持任意录音驱动照片。

照片说话不强制先创建长期形象。用户希望反复使用时，另行进入“创建形象”；一次创作成功不等于自动得到可复用的供应商形象标识。

### 5.4 形象库与创建形象

形象库管理可用的公共形象、本企业获授权的形象及创建中的形象。形象卡展示可验证的预览、名称、可用状态和支持用途；接口未提供预览时，使用已授权维护的预览或明确占位，不生成假人物充当真实可用形象。

创建形象是独立页面：选择素材方式 → 上传并检查要求 → 提交创建 → 等待状态 → 查看形象 → 返回原创作。

状态包括未提交、处理中、可用、失败、不可用。用户无需停在页面等待，但只有可用且兼容本功能的形象能用于生成。公共形象是否支持克隆后的全部玩法不得假设。

形象是出镜资源，个人 IP 是表达设定。二者可关联默认选择，但不能互相替代。

## 6. 音频页面设计

### 文本配音

左侧：文稿、声音选择、当前服务支持的设置。右侧：真实试听/生成结果、时长、下载及“用于数字人音频口播”“用于视频合成”。

同一段用户已确认的音频，转入数字人口播时使用原文件，不偷偷再次合成一遍。是否能按字词修改取决于实际音频服务能力，不能默认承诺。

### 声音库 / 创建声音

声音是跨功能资产，归音频模块管理；数字人中的选声按钮打开同一个资源选择器，没有第二套声音库。

创建声音需要源音频与服务要求的信息，是独立任务，不等于上传音频驱动数字人。支持从创作页进入创建，保存原草稿，完成后返回并带入兼容声音。

重要：当前飞影文档的声音参数修改是针对声音资产的接口，并非所有参数都属于一次生成任务。不能把这类修改直接做成某个草稿中的临时滑块，导致其他创作共用的声音被一起修改。首轮先用默认声音设置；需要临时调速时，应选择明确支持逐任务设置的服务或单独的音频处理 API。

## 7. AI 视频与素材成片页面设计

### AI 视频

文字生成与图片生成各有独立页面、草稿和历史。文字页突出画面描述；图片页突出参考图和运动要求。首尾帧、参考视频和续写在该模块预留子功能位置。

时长、比例、清晰度、声音等由已接入模型的有效组合决定。切换生成方案时检查参考素材与已有设置兼容性，不静默丢参数。不存在所有供应商通用的无限时长或画面比例。

不能把有声视频默认当作可以精准照读文稿的口播视频。选用的生成服务是否支持音频输入、是否包含生成声音、输出能否继续编辑，分别说明。

### 视频合成 / 素材成片

左侧素材；中央按顺序排列场景卡；右侧预览。场景卡表达“该段画面、对应配音、字幕、时长”，不用专业时间线作为首轮必备。

来源可包含用户实拍、AI片段、数字人口播及配音。需要支持顺序调整、片段替换、画面适配、原声和配音选择、字幕、封面、合成输出。处理交给 API，系统维护场景结构。

成片时长由可用素材和音轨共同决定。素材不足时让用户补充、缩短方案或明确选择允许的补足方式，不静默拉伸或重复素材。不支持的后期效果不展示可执行控件。

不设无实际作用的“发布平台”。导出包含视频、封面和配套文案；渠道适配只有具有实际规则和输出差异后才增加。

## 8. 文案、图片与图文的关系

文案模块可以拥有公众号、口播、朋友圈、小红书等专用子页面，共享编辑器但各有输入提示、输出结构、模板和导出方式。用户选口播脚本，不等于系统立即生成数字人或扣视频费用。

图片模块分别提供：AI生图（描述到图）、图片修改（原图加修改要求）、海报/封面（明确布局及可替换字段）。海报的可编辑文字依赖模板与合成能力；扁平生图不能承诺像设计源文件一样编辑。

小红书图文是一套多页作品。首轮可定义其流程和位置；只有多页排版、排序、逐页修改和整套导出打通后，才显示“图文完成”，不能拿一篇文案代替。

## 9. 品牌、IP、资源与作品的关联

企业空间决定资料和资源归属；品牌资料保存真实业务信息；IP档案保存定位、受众、表达方式；数字人形象和声音保存媒体资源；本次创作记录具体采用的版本。

IP创建独立支持：手动填写、AI简短访谈、参考对标分析。输出候选定位，用户确认后保存。对标信息提供参考方向，不能覆盖自己的经历、资质与案例。

IP可关联默认形象、声音，但音频口播使用原音频，不会因为IP默认声音不同而改声。未建立IP也能生成通用内容；品牌或IP更新不静默改变历史作品。

资料分工：品牌事实回答“是什么”；IP回答“谁在说、对谁说”；Skills回答“采用什么方法”；模板回答“按什么结构呈现”；API回答“如何产出媒体”。不自动沉淀或学习个人记忆。

## 10. 连续操作与互相传递

- 文稿 → 文字口播：带入原稿及品牌/IP，不复制成两份失联文本。
- 已生成配音 → 音频口播：带入选中的实际音频版本，不重新TTS。
- 数字人口播/AI片段 → 视频合成：带入对应文件，可保留原声；追加包装属于新成片版本。
- 图片 → 图片生成视频：带入原图；如要照片说话，由用户明确选择对应工具。
- 对标 → 创作：带入参考材料与其完整程度，不自动生成全部媒体。
- 创作中缺少形象/声音 → 创建资源 → 返回原草稿，保留文稿和素材。

资源ID由供应商拥有，不假定跨供应商互通。切换服务时，只能选择兼容资源；音频文件可作为跨服务传递方式，但是否被接收仍需验证。平台不能把同一供应商总账号下的全部私有资源直接展示给所有经销商。

## 11. 对标入口保留的约束

单篇和账号分开识别；指定条数是获取上限而非成功保证。列表、正文、口播转写和画面分析分别记录。默认筛选已保存内容，补采另有明确动作。

账号分析注明样本数、时间和内容覆盖；只有发布文字时，不显示“口播已获取”。播放地址实际不可用时不显示可播放按钮。API失败不自动转免费抓取。

## 12. 任务、预览与费用

生成前展示布局或资源示意，并明确它不是成品。提交后显示真实阶段，完成后展示实际可播放/可下载文件。

关闭页面保留草稿与供应商任务编号。超时先核查原任务，不自动重复付费。重复点击不创建重复任务。音频或画面部分完成时可保存，后续步骤失败不丢掉已有成果。

修改文稿只修改草稿；旧视频仍绑定原文稿和资源版本。重新生成说明影响范围和新增消耗，保留旧成果。公共设置与单次设置明确区分，防止一项局部调整改变其他任务。

原始文件本地保存，与上传所选素材给云API处理是两件事。媒体上传范围、结果保存和供应商临时地址有效期必须在接入时确定。

## 13. 功能预留方式

设计结构中写明未来功能属于哪里，以及需要的输入输出。对外可用页面默认只显示已接入功能；需要展示路线时，在模块的“更多玩法”统一标“规划中”，不放能点击生成的空按钮。

暂不开发：双人播客、手持商品互动、数字人唱歌、AI PPT、直播互动、复杂专业剪辑、自动知识沉淀。视频翻译归媒体处理/视频合成扩展，不塞进文字配音。研发顺序可调整，功能归属不因此改变。

## 14. 接入与开发顺序

1. 小样本验证：飞影文字口播、音频口播、照片说话、形象和声音创建分别验证；另选视频、图片和合成API验证核心输入输出。只有公开文档不算通过。
2. 明确供应商支持的字段、组合、资源归属、素材限制、状态、成品获取及费用；不能把官网功能清单直接复制成承诺。
3. 页面原型走通：缺资源→创建→返回；文案→配音→音频驱动→成片；对标→自己的稿件→作品。
4. 分功能实现真实闭环。每个工具都有独立验收，不以一个API成功代表整个模块完成。
5. 最后完善多企业服务、额度和运营交付。当前本机账户不等于商业多租户。媒体与私有资源的归属隔离从数据结构开始约束。

## 15. 核心验收场景

| 场景 | 应有结果 |
|---|---|
| 有录音，无克隆声音 | 进入音频口播，选可用形象即可；不强制创建声音 |
| 有文稿，无形象 | 可选公共形象，或创建形象后返回原稿 |
| 只有一张人物照片 | 进入照片说话，不误进产品图生视频 |
| 产品图片想运动起来 | 进入AI图片生成视频，不出现数字人选声要求 |
| IP默认音色与上传录音不同 | 保留上传录音，不偷偷改声 |
| 创建形象失败 | 草稿保留，可换形象，不伪装成生成成功 |
| 改稿后下载 | 明确草稿和已生成成片的版本差异 |
| 切换服务或模板 | 检查兼容性，保留原草稿，解释需更换的字段 |
| 同企业多任务用同一个声音 | 单次创作不会无提示修改共用声音资产 |
| 不同经销商使用平台总API账户 | 私有形象、声音和作品不跨企业泄露 |
| 供应商返回任务成功但下载失败 | 显示结果保存未完成，不重复提交生成 |
| 规划功能尚无API | 保留设计位置，不制造可用状态 |
