# 0.16.0 创作交互与图文编辑

## 使用变化

1. 删除顶部独立操作区。访谈在对话框响应，生成中、失败或完成留在作品区域。
2. 对话和创作要求：Enter 发送/继续，Ctrl+Enter 换行；中文候选确认不会提交。文稿正文属于编辑器，Enter 正常换行，Ctrl+S 保存。
3. 图片页先选模型，再填画面要求、参考图和生成参数。后台绑定是默认，前台允许选其他已上架兼容模型。选择不兼容服务时会取消旧参考图与参数。
4. “AI 优化提示词”只生成候选文字，可以编辑、采用或保留原文；不会自动触发生图。
5. 图片修改使用所选原图和修改要求；Images 模型走 multipart `/images/edits`，无参考图走 `/images/generations`。阿里云和飞影保持各自独立参数，不合并成虚假通用接口。
6. 图片点击放大，滚轮缩放、拖动平移，适应窗口复位，Esc 关闭。
7. 文稿生成后默认显示 Markdown 排版预览。切换编辑/双栏，可展开为宽屏文稿工作区；支持标题、粗体、斜体、列表、引用、链接和插图。
8. 插图可上传、粘贴、拖入，或从素材库选择；图片归属于当前文稿。编辑自动暂存本机，点击保存写入数据库和新版本；未保存修改时禁止 HTML 导出。
9. HTML 导出内嵌图片，可离线查看。外部平台分发本版未开发；保存与导出不会发布。

## 接口能力与真实结果

- Images 标准尺寸与 quality 参数来自接口文档；GPT Image 2 系列提供更多尺寸。尺寸、比例不作为互相矛盾的独立字段：图片通过“图片尺寸 / 比例”统一选择。
- 文生视频按已接入的 wan2.7 两个版本提供模型选择、720P/1080P、画面比例和2–15秒；图生视频使用独立参考图输入和该版本支持的清晰度。没有虚假的“发布平台”参数。
- 未配置的服务如实提示，不能提交。可选模型不绕过管理员停用功能。
- **2026-09-22 CPA 实测：** 文本提示词优化完成；gpt-image-2.5 接收参考图编辑并返回图片。但请求 2048×2048、quality=medium 时实际图为 **1254×1254**。系统保留服务原图，显示实际尺寸与请求差异。未通过插值放大伪装2K，未反复调用研究网关行为。
- 视频、飞影数字人和其他付费提供商本次只做代码/接口契约验证，未做真实付费生成验收。

接口依据：[Images 编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)、[阿里云文生视频](https://help.aliyun.com/zh/model-studio/text-to-video-api-reference)。参考 Fengsha.chat 与风沙 AI 电商的交互思路，未修改其代码或配置。
