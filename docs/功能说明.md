# 梯见工作台功能说明

> 0.9.0 知识功能更新：原文直接提问、Wiki 自动整理、对话记忆、文件夹和参考范围，详见[当前设计与使用说明](个人知识工作台-设计与使用.md)。旧版候选审阅仅保留用于兼容。

适用版本：0.12.0。本文描述当前源码实现，不把设计稿、第三方项目宣传或未来计划算作已交付能力。

## 1. 第一次使用

1. 启动桌面工作台，创建本机账户。首次注册账户拥有本机管理权限。
2. 选择一个专用空目录作为工作区，保存资料、文稿和知识文件。
3. 先导入一份文稿或一篇公开文章，确认资料能够保存、搜索和重新打开。
4. 需要 AI 时，在设置中心的 AI 与创作偏好进入管理后台配置模型；需要公众号备用服务时再配置次幂。

本机账户不是微信账户，也不是 GitHub 账户。应用登录不会自动赋予公众号访问权限。普通资料管理和文稿编辑不要求购买模型或次幂服务。

## 2. 今日工作：从目标开始

在首页输入具体目标，例如“分析这份旧梯改造资料，提出三个面向物业的选题”。系统根据目标选择研究、写作、对标或定位类型，进入可持续的任务会话。也可以从资料、雷达和对标文章进入任务，将所选资料带入上下文。

最近工作用于返回已有会话；相同目标及参考资料会尽量复用已有任务。会话、文稿、原始资料分别保存，避免把聊天记录直接当成最终稿。

模型连接缺失或调用失败会明确显示原因；不会用预制答案冒充 AI 成功。

## 3. 行业雷达：从线索到选题

### 关注信源

在设置中心的雷达信源模块管理公开网页与 RSS/Atom 信源，读取后记录最近成功时间和错误。可按日期、关键词筛选，并将线索保存为原始资料或带入选题任务。添加信源时可预览识别结果，单篇文章链接与订阅列表会分别处理。

日期范围默认本月 1 日至当天，也可使用其他期间、清空日期查看全部。页面更新不代表所有信源都更新成功，应查看各信源状态。

### 平台热榜

当前界面提供微博、知乎、头条、抖音、小红书、百度热榜，来自 60s 公开聚合服务。程序限制频繁更新；实际可用性取决于服务及平台返回。

不同平台热度口径不同，不直接合并为统一排名。电梯相关筛选按关键词匹配，不代表已经由 AI 验证行业相关性或真实性。

## 4. 对标研究：账号、文章和记录集中管理

添加关注账号，填写平台、名称、代表文章及关注理由。选择账号后有四个主要区域：

| 区域 | 用途 |
|---|---|
| 已保存正文 | 阅读、筛选、编辑和删除本地正文，带入分析与创作 |
| 订阅发现 | 查看自动订阅及手动订阅检查发现的文章，标记未读并补采正文 |
| 手动获取 | 分别选择粘贴链接、导入文稿、查询目录后采集正文 |
| 获取记录 | 触发方式、提交／开始／结束时间、逐篇结果和删除入口 |

可以粘贴一篇或多篇文章，也可以导入已有文稿、字幕或文档。公众号身份以文章里的发布账号标识核对，不能把同名搜索结果自动当成同一个博主。

**目录与正文是两种成果。** 目录包含标题、发布日期、链接；正文成功保存后才能本地阅读或导出正文。界面分别显示“已发现”“正文已保存”“采集失败”，不会把目录数量算成正文成功数量。

免费正文读取、微信读书订阅、次幂历史查询及费用详见[公众号采集与费用](公众号采集与费用.md)。连接配置迁入设置中心，业务页只保留真实状态和配置链接。布局、来源与时间口径详见[页面导航与获取记录](页面导航与获取记录.md)。

## 5. 采集过程与结果反馈

点击采集后显示提交及执行状态，批次结果留在当前账号页面。每篇可查看成功、失败及原因，成功内容可以原位阅读；“详情”在当前页展开，不要求跳到任务中心。

免费桌面采集遇到微信验证时打开原文窗口，由用户完成验证。完成后尝试继续本批；关闭验证窗口停止剩余采集。仅关闭工作台内的文章抽屉不会取消后台任务，需用取消按钮停止。

任务中心用于查看跨模块的执行状态。排队或执行中的任务可请求取消；中断、失败和取消后的任务按类型允许重试。付费正文补采必须回到文章库重新选择并确认费用，不通过通用重试绕过确认。

一次批量任务可以部分成功，整体“执行结束”不等于每篇正文都获取成功，应以成功和失败数量为准。

## 6. 内容中心：写作、编辑和版本

内容中心提供作品列表、看板和计划。任务中可以选择运营身份、参考资料和工作类型，围绕同一目标继续对话。

- 模型产生的新稿作为候选版本，明确采用后才进入正文。
- 文稿可以独立手工编辑和保存；历史版本可查看、恢复。
- 页面切换和重新打开保留本机草稿；正式保存写入数据库和工作区。不要依靠浏览器缓存替代备份。
- 同时在多个窗口或外部文件修改时，版本冲突会阻止静默覆盖。
- 核查结果绑定被检查的稿件版本；正文变化后不能沿用旧核查当作新稿已通过。
- 内容计划用于安排工作，不能直接在外部平台定时发布。

可导出 Markdown、公众号 HTML 或复制排版。导出与实际发布分别登记，软件不会因为导出文件就标为已经发布。

## 7. 我的 IP：定位与表达偏好

维护运营身份、受众、渠道和定位信息，也可通过访谈任务逐步整理。后续内容任务选择对应身份，帮助模型沿用一致的受众和表达方向。

身份资料是可编辑的业务设定，不等于外部账号实名认证。候选定位需要用户核对，不能把模型假设写成已经发生的经历。

## 8. 知识资产：资料与结论分开保存

原始资料、会话、知识和个人记忆分别管理。资料可直接保存；会话可提炼为摘要；进一步提炼的知识进入候选待办，由用户审阅后确认。

知识记录保留来源、地区、适用时间和范围。已确认且允许 AI 使用的相关知识可按关键词进入后续任务；这是上下文检索与复用，不是训练或微调模型。

知识维护检查外部文件变化、过期记录、重复正文和缺失依据。外部 Markdown 与应用同时改动时保留冲突双方，交由用户处理，不自动删除历史。未索引附件不是可自动恢复的知识记录。

## 9. 文档导入与资料管理

| 格式 | 当前处理方式 |
|---|---|
| TXT / Markdown / CSV / SRT / VTT | 读取 UTF-8 文本 |
| DOCX | 提取段落和表格文本，不保持完整页面版式 |
| PDF | 提取文字层；扫描 PDF 需先做 OCR |
| 直接粘贴 | 保存标题、正文、可选原始链接及日期 |

单文件上限 10MB，PDF 上限 200 页，提取文字上限 50 万字符；DOCX 展开上限 40MB。无法读取的文件会说明原因，不保存空内容作为成功。

资料管理支持按类型、日期和标题筛选。单日期默认当天，所以找不到历史记录时先检查日期条件。对话可继续或提炼，资料可编辑，并可设为不用于 AI。

## 10. 删除与回收站

任务、采集记录、文章目录、提醒、资料和免费订阅等提供删除入口。删除默认移入回收站，正常列表及 AI 上下文不再使用该记录，可在资料管理切换回收站恢复。

删除记录不等于擦除磁盘原始文件或历史备份；工作区文件保留。删除对标账号也不等于级联删除已保存文章。运行中的任务应先取消；免费订阅应先暂停并等待当前检查结束再删除。

管理员审计记录与普通任务记录不同，不承诺任意删除所有审计条目。当前没有自动永久清空日志或按天销毁历史的功能。

## 11. 平台账号

通过独立窗口登录，按平台保存会话；同平台有多个账号时可选择。普通平台网页读取与公众号免费正文/微信读书订阅使用各自的会话路径。

“已保存连接”只表示登录资料已经保存，不表示目标文章可访问；“已登录”也不表示平台允许全量采集。遇到扫码、验证码或身份确认，由用户在平台页面完成。

## 12. 发布与数据复盘

用户在外部平台实际发布后登记链接。阅读、播放、点赞等指标由用户录入，未知留空，不能作为零。不同渠道分别查看，不混合计算不同口径。

可将本期数据送入研究任务形成复盘建议；模型应区分已有观察与推测。当前没有自动拉取所有平台表现数据或自动发布功能。

## 13. 设置与管理后台

| 配置 | 说明 |
|---|---|
| 模型服务 | 填写服务名称、HTTPS Base URL、自己的 API Key 与协议 |
| 模型目录 | 发现模型、实际测试、验证后上架；发现模型不等于调用成功 |
| 功能绑定 | 为写作、研究、对标、选题、定位、核查、知识整理选择默认模型 |
| 工作偏好 | 按工作类型维护提示词；保留来源核对及工具权限边界 |
| 行业资源 | 维护草稿、检查、上架状态与版本，影响后续任务 |
| 用户 | 本机用户启停与管理员权限范围 |
| 工作区 | 选择本地目录、导出备份、合并导入、检查外部文件变更 |
| 次幂 | 加密保存 AppID / Secret，提供开通、文档和报价链接 |

模型测试和正式生成会向用户配置的服务发出请求，费用由服务商计算。次幂扣费确认只负责次幂业务，不能理解为所有 AI 调用都免费。

## 14. 通用交互与日期

单日期表单默认操作当天，范围日期默认本月 1 日至当天，日期时间默认本地当前分钟。已有记录的日期优先保留，用户可以修改或按允许范围清空。默认日期是便捷输入，不是对历史资料发布日期的真实性证明。

弹窗和抽屉支持点击外部空白遮罩收起，点击内容区域不会关闭。关闭弹层与取消后台任务分别处理。

## 15. 当前不包含什么

不包含官方任意公众号发文事件、保证完整的公众号全历史、验证码绕过、视频号自动字幕提取、云端全天托管、生产多租户、平台自动发布、代码签名安装包、自动升级或积分计费。各平台能力必须以自己的账号与实际文章验证。
