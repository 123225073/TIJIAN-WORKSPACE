# 0.32.3 文章画布与配图验收

本次按截图中的问题简化内容矩阵，不改变用户已保存稿件、模型配置或发布账号。

## 已实现

- 内容矩阵五个子步骤可收起和展开，当前作品、选题、步骤不重置，刷新保留偏好。
- 公众号和矩阵各图文平台均只有一个文章画布。标题直接在纸面编辑，正文保留可视格式；阅读预览与编辑互斥。
- 纸面采用深色字与暖白底，控制阅读宽度、段距和标题层级。正文随长度增长，避免固定高度溢出盖住操作栏。
- 右侧常驻文章配图，直接选择比例、1–4张数量。文章上下文、模型、质量与行业插画风格自动取默认值。
- 图片先展示缩略图，用户选择后再插入文末；可使用已有素材或单独上传，支持放大与失败重试。
- 配图沿用持久化批次、请求去重和账号隔离。原请求状态不明时只核查，不自动重复收费提交。保留旧三图任务的恢复入口。

- `scripts/test-content-matrix-ui.mjs`：真实浏览器与隔离SQLite，验证流式母版、编辑、刷新恢复、并发版本冲突、侧栏折叠、公众号/知乎单画布、插图保存恢复、1366/1920布局、发布控件与账号配置。
- `scripts/test-article-image-rail.mjs`：8组真实组件浏览器测试通过。覆盖显式点击前无写请求、比例数量真实传递、未知任务恢复、历史图保留、只重试失败、账号切换止写、插入失败不丢图文；配图素材距栏顶部约217px。
