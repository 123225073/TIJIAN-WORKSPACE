# 0.11.0 对话驱动工作台

## 使用
- 工作类型新增“日常沟通”，新任务默认使用。示例：“结合所选资料回答这个问题”“根据上面的沟通整理我的 IP”“记住我希望回复简洁、直接”。
- 定位访谈会在每轮回答后判断方案是否足够完整，完整时自动生成待写入卡片。旧定位会话可点“梳理已有对话”。
- 身份名称、定位、受众、表达偏好、观点、完整方案由模型整理，不需要重填。缺失事实不会补造；建议列在待核对说明中。
- 点击“确认写入”，或选择“微调内容”；暂不采用可以忽略。已有目标来自当前对话选择的身份或该对话之前保存的身份；需要更新其他身份，先在对话中选择该身份，再要求整理。
- 确认后身份关联当前对话，后续写作使用所选身份；记忆进入知识资产的个人记忆页。

## 实现范围
- 复用现有模型网关、后台任务、检索、SQLite和版本记录。没有新增外部Agent框架或MCP依赖。
- 模型以约束JSON提出 profile / memory 操作，由服务端白名单接口验证、等待用户确认、写入；不是任意工具执行器。
- 日常问答仍遵循参考范围；不宣称联网搜索、平台采集或外部发布已执行。
- 整理读取完整当前对话。超过120000字符明确报错，不静默截断。一次生成一个待写入结果。
- 写入检查对话变化、目标版本、当前用户、运行状态；重复确认不重复建档。重新发言会替换旧待写入结果，已写入档案仍保留。
- IP整理使用当前模型或定位默认模型；日常沟通有独立模型偏好与后台角色设置。

- 真实页面与隔离SQLite验证生成结果、刷新后保留、确认写入、普通问答不出现IP卡片、个人记忆写入。
