# 梯见：访谈融合与商业版信息架构

## 两位受访者的共识与差异

两份录音已在本机转写并复核关键段落。转写受口音、多人插话影响，以下为主题归纳和约略时间位置，不作为逐字会议纪要。文件名依次为《华宝南路.m4a》（约88分钟）与《华宝南路 2.m4a》（约30分钟）。

| 录音与位置 | 沟通中反复出现的重点 | 设计响应 |
| --- | --- | --- |
| 第一份约 5—6、13—15 分钟 | 首页聊天入口要收敛，新用户要容易理解 IP 定位和起步路径 | 首页减少入口，保留简短产品说明与明确行动 |
| 第一份约 20—23、30—31 分钟 | 行业雷达、对标内容要有真实来源；仅有文字无法冒充看过视频画面 | 对标数据缺口明示，采集与分析分层 |
| 第一份约 38—39、46—49 分钟 | IP 与品牌关系、创作后按平台交付图片和文案 | 品牌事实并入 IP，交付页区分平台并绑定真实素材 |
| 第一份约 70—72 分钟 | AI 对话应能回答销售、软件使用、电梯行业知识 | 个人知识检索加系统资料管理 |
| 第二份约 0—5 分钟 | 选题留下来重复使用，允许人工整理和恢复 | 选题库持久化、归档/恢复、同题多稿 |
| 第二份约 5—10、12—13 分钟 | Skills 方法与真实信息采集要分开，首批聚焦公众号、视频号、抖音 | 提示词方法可管理，采集依赖明确数据源，三平台交付 |
| 第二份约 15—18、23—28 分钟 | 发布前要看可编辑内容与封面；数字人口播和真人剪辑有区别，功能少而清楚 | 交付稿可编辑并选择素材；未接通的媒体能力显示边界 |

- 第一位更关心新用户打开软件后的理解成本，以及把现场照片、工作经验快速做成能用的内容。他希望首页直接讲清收益，入口少，移动场景更顺手。
- 第二位在最终沟通中进一步明确了完整链路：行业常青问题、近期资讯、社会热点和个人 IP 汇入选题库；选题后按平台生成可编辑的交付内容；素材、作品和数字人资产能接续使用。
- 本轮以最终确认的“找方向 → 做内容 → 留成果”作为主结构，吸收第一位“快速看懂、少点按钮”的要求。资料问答是横贯这条链路的独立入口，不把首页变成一个占满屏幕的聊天框。

## 已落地的页面结构

| 一级入口 | 用户应看到什么 | 页面边界 |
| --- | --- | --- |
| 首页 | 一句话说明产品，三个开始路径，最近草稿 | 不显示尚未开放的玩法 |
| 问问梯见 | 销售沟通、工作台使用、电梯知识三个提问起点，历史对话 | 模型未配置时明示不可提问 |
| 知识库 | 原始资料、自动整理或人工确认的知识页、个人记忆 | 自动整理不等于事实已核实；需核对候选要人工确认 |
| 灵感与对标 | 行业雷达、已绑定账号、真实作品样本和可用分析 | 付费查询需确认，缺失口播/画面不补造 |
| 选题库与平台交付 | 雷达、对标、手工想法和 AI 建议归档；按公众号、视频号、抖音分别编辑交付稿 | 保存、导出不代表发布；AI 生成依赖已验证文本模型 |
| 我的 IP、出镜形象、声音资产 | 个人定位和业务事实；获授权的形象与声音 | 克隆/生成依赖已验证服务，未接通时显示不可用 |
| 一站式创作、文案、图片、AI 视频 | 从主题进入适当工具，保留草稿和生成状态 | 没有服务时只允许编辑草稿 |
| 作品与素材 | 生成记录、上传素材两个标签 | 导出不代表发布 |

已去掉“个人偏好”及首页“规划中”展示。软件更新留在账户菜单下的“关于与更新”。现有品牌资料留在“我的 IP”内作为代理品牌与业务事实的补充，不再占单独导航入口。旧路由仍可访问，以免既有草稿和历史链接失效。

新建工作区会得到初始管理员 `admin / admin`；已有用户库不覆盖。管理后台支持修改密码与新增普通用户，默认关闭公开自助注册。正式交付前应先修改初始管理员密码。

## 知识问答的实现边界

提问进入现有持续对话，默认检索当前账户的原始资料、知识页和有效记忆，再把检索片段交给已配置的文本模型。自动整理的知识页要回到原文核对关键事实。行业事实要附资料编号；冲突与缺口直接说明。销售话术属于建议稿，不充当真实报价或服务承诺。软件使用问题可使用随代码维护的产品操作说明，但不能假装已经点击、配置或发布。没有绑定已验证文本模型时，入口明确提示管理员配置。此路径不要求 Codex 常驻，也不默认联网搜索；行业雷达与外部采集是另一组受控能力。

## 访谈中的技术问题

- “让 AI 搜热点”并不意味着模型天生知道实时热点。工作台应先调用明确的数据源（行业雷达、平台开放接口或经授权的采集服务），记录链接、发布日期、作者及采集时间；再做去重、与电梯业务相关度、时效、信息完整度和来源可信度评分。AI 负责归纳及提出切入角度，评分理由与原始证据都应让用户看见。当前找题会读取用户已保存的资料与 IP，**不会自行联网搜热榜**；没有真实材料时仅给方向建议。
- Skills 适合承载选题筛选、分镜结构、销售话术等可版本化的内容方法；搜索、抓取、下载、转写与视频理解必须有独立工具或服务接口，并受权限、费用及证据约束。工作台不需要内嵌 Codex 才能提供这些能力。
- 分析对标视频不一定要永久下载到用户电脑。若内容服务或多模态模型支持直接读取可访问的视频 URL，可由服务端临时获取音视频/关键帧后分析；若只拿到网页分享链接、无可访问的视频流，不能宣称看过画面。账号研究可先用标题、封面、发布时间、播放/互动和文字说明做初步分析；口播、镜头、动作等结论必须在拿到实际媒体或可靠转写后才生成。
- 图片生成视频、照片驱动口播、真人素材训练形象以及声音克隆是不同能力。后台目录按真实输入与用途分类；正式开放前分别核对授权素材、接口请求、成本和输出质量。

## 选题与交付的已实现边界

1. 雷达线索、对标文字样本、手工想法以及 AI 建议可以进入选题库。选题保留来源资料、版本、关联身份、交付稿数量；同一来源标识重复添加会复用记录。
2. 从选题进入公众号、视频号、抖音交付页，分别编辑标题、正文或口播、分镜、封面建议、标签；可选素材库中的真实封面图片，视频号与抖音还可关联成片。支持手工保存、AI 填写、Markdown 导出。导出稿记录所选素材名称，媒体文件需分别取得。AI 找题和交付稿生成必须有已绑定且已验证的文本模型；未接通时只能手工编辑。没有自动发布能力，页面始终显示草稿状态。
3. 选题可归档与恢复；找题建议一次可选 3、5、10、20 条。归档保留已有交付稿，恢复后继续创作。
4. 管理后台增加媒体服务商和模型目录，区分 AI 视频与数字人口播，支持上架、下架、归档及绑定前台入口。视频目录只列 Seedance 2.0 和 2.5。Segmind、WaveSpeedAI 等为候选供应商，价格和能力未经本工作台实测验证。
5. 管理后台增加系统知识资料，可存草稿、发布和停用。发布前须填写来源、适用范围和生效日期；未生效或已过期的资料不进入后续问答。发布的销售口径或行业资料带版本及资料 ID 进入后续知识问答；个人原始资料与知识页仍按账户隔离。

## 尚需真实服务接入

视频中转 API 适配器和数字人口播中转 API 适配器尚未接入；填写 Base URL、API Key 或上架模型不会自动使生成能力可用。前台保留可编辑草稿、模型目录与禁用状态，不会伪造生成成功。正式接入时需逐一核对真实模型标识、输入参数、异步回调、成本和合约授权，再做小样实测。形象克隆、声音克隆、照片驱动视频与真人素材口播应按真实供应商能力分别开放，不能以图生视频冒称克隆。
