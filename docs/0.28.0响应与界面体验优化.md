# 0.28.0 响应与界面体验优化

## 操作响应

草稿列表原来逐份解析任务、对话和作品的归属，模型目录还重复打开数据库读取配置。改为一次读取归属元数据、每次请求批量读取相关配置，保留原有所有权与历史绑定规则。含迁移的操作在同一写锁内完成配置快照和迁移，避免旧值覆盖管理员更新。请求结束即丢弃配置快照；下一次请求会读取最新配置。

一站式创作从明确作品入口进入时，资料与流程恢复并行读取；页面保留真实加载状态和草稿校验。

同一份现有数据的隔离副本中，目录与草稿读取从约1秒分别降至约9和14毫秒，这是本机测量值，不是所有机器、文件或服务的耗时承诺。完整界面的图片编辑冷/重复进入也通过真实后端计时验收；付费模型创作时间取决于供应商，未纳入此性能结论。

## 图片编辑

扩大画布，使用暗色低干扰背景，底部结果栏与画布对齐；结果保持单行，溢出时左右滚动。矮屏保留可用画布并允许纵向滚动。工具、结果和菜单的普通、悬停、禁用状态都使用匹配背景与文字。

图片右键选择“添加到图片编辑区域”，先保存当前可见编辑稿，再用原图建立独立编辑稿，避免替换已有草稿或误提交 AI。缩略图使用对应原图；旧文章插图和可读取静态图通过既有上传流程导入。原图、保存或登录状态异常时明确提示，不强行跳转。外部图片受浏览器跨域读取限制时，需下载后上传，不绕过权限。

## 公众号发布准备

“保存发布稿”旁直接显示保存中、版本、成功或失败；重复点击不会并发写入。409冲突保留当前编辑；保存期间又输入的内容保留并提示再次保存。已写入但列表刷新失败与写入失败分开显示。

连接面板以清晰标题和三步操作展示：本机保存、同步草稿、确认发布。账号设置、IP白名单说明默认折叠。保存本机不触发微信同步或公开发布。

## 主题与验证范围

修复共用组件从旧页面复用到新页面时漏掉主题祖先的问题，覆盖平台热点、信源向导、阅读抽屉、弹窗和共用按钮。正文纸面和首页保留各自配色、布局。

验收使用隔离 SQLite、真实上传图片与实际 API；以真实界面的可见状态、保存后重载和原图对应关系为准。跨页面主题覆盖普通、悬停、禁用及错误状态，并与修改前基线对照。各项结果及安装、远端发布、数据保留与清理记录在本机交付报告中保存。未执行真实付费生成或公开平台发布；管理员网页不计入本轮创作端主题覆盖。

本版实际检查：157 项相关后端回归通过；最终生产前端的图片编辑/右键11项、导航响应3项通过；公众号保存6项通过；创作端主题82状态、984文字样本无对比度失败。最终生产前端与隔离真实后端的图片编辑首次/重复就绪计时约201/138毫秒。不同数据和设备会有差异。
