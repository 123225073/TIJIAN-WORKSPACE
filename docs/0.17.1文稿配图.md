# 0.17.1 文稿配图

## 确认的问题

本机当前运行的安装版本为 0.16.0。旧编辑器将同名图片素材显示为「图片创作」文字按钮，点击立即插入。0.17.0 已修复素材缩略图，但缺少文稿内直接生成配图的入口。

## 本次交付

- 素材库插图：搜索、缩略图、选中、右侧预览、确认插入，分开操作。
- AI 生成配图：输入要求、优化后选择采用、模型与实际可用参数、费用确认、生成结果预览。
- 插入位置可选光标处、文章开头、文章末尾；预览与生成均不直接修改正文，确认后仍需保存文章。
- 配图使用现有媒体 API 和模型目录，生成记录与媒体文件进入现有数据库/素材库；请求编号和画面要求按用户/文章缓存，可恢复核查。
- 同名素材通过缩略图、尺寸和日期区分；可以点击放大。

## 验证边界

前端构建通过，27 项隔离页面检查通过，包括选中后正文不变、生成后正文不变、指定位置确认插入、Markdown 保存/恢复/带图导出。测试图片明确标为隔离测试素材，未执行新增真实收费调用。该版本没有改变媒体后端接口。当前用户安装未自动覆盖。

打包后端隔离启动、媒体探测、重启与原有配置记录保留检查通过。
