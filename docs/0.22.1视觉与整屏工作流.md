# 梯世界 0.22.1：清晰配色与整屏工作线

本轮针对实际使用截图中的三个问题调整：全站过暗、选中后浅底浅字，以及一站式创作头部和步骤占据过多高度。

## 配色与阅读层级

| 区域或状态 | 背景 | 文字与识别方式 |
|---|---|---|
| 工作区 | 铂金灰 `#f3f5f8` | 深石墨 `#18263a` |
| 表单、内容、素材 | 白色 | 辅助文字 `#536278`，可辨认的边框 |
| 主操作 | 钴蓝 `#245bcc` | 白色文字 |
| 选中 | 淡蓝 `#e7efff` | 深蓝文字和明确边框；选题行保留左侧标记 |
| 禁用 | 灰蓝底 | 清晰灰色文字；不再通过整块半透明降低可读性 |
| 导航 | 石墨蓝 | 浅色文字；当前入口用蓝色标记 |
| 品牌点缀 | 少量香槟金 | 用于品牌和入口标记，不承担正文阅读 |

首页电梯场景用明亮的玻璃表面承载对话和工具，不让背景照片遮蔽文字。选题页的工具栏、默认行、悬停行和选中行分别配对背景与前景颜色；文稿编辑、双栏和预览按钮同样明确区分。

文章纸张继续保留自己的正文和标题颜色，人工指定文字颜色保留，不因界面主题改写文章格式。

## 一屏看清五步

仅保留一组“一站式创作”抬头、作品切换与简短进度，不再重复显示口号和介绍。01–05 使用醒目的大编号，已完成状态仍保留编号和勾选。

桌面左侧五步工作线及内容、平台分支完整展示；右侧长表单在自己的区域滚动。用户切换步骤时，工作线保持可见。长作品名称显示省略并提供完整标题提示，原内容不裁剪或改写。较窄的手机页面采用自然滚动。

本轮仅调整视觉、布局和相应验证，不改变 AI 对话、不同流程及独立工具的草稿归属规则。
