# 公众号采集、订阅与费用

适用版本：0.6.0。价格为本版界面使用的人民币参考价，不是平台价格承诺；实际以[次幂官方报价](https://www.showdoc.com.cn/2265380957870963/11559023150418150)和账户账单为准。

## 先区分四件事

| 阶段 | 得到什么 | 不能推定什么 |
|---|---|---|
| 识别账号 | 从一篇原文核对发布公众号的标识 | 不代表已经拿到其他文章 |
| 获取目录 | 标题、日期、链接等元数据 | 不代表正文已经下载 |
| 保存正文 | 正文进入本地资料与文章库 | 不代表图片、视频和 PDF 已离线保存 |
| 订阅更新 | 定期发现新的目录记录并尝试保存 | 不代表官方实时推送或完整全历史 |

## 方案一：免费读取公开正文

已有文章链接时，在桌面版选择“采集所选正文（不收次幂费用）”。浏览器读取真实原文，检查有效正文后保存到工作区。正文有缓存时可以直接复用。

遇到微信环境异常或验证要求，会打开平台页面让用户处理。程序不会破解或绕过验证码；完成后尝试继续，关闭验证窗口则停止剩余采集。被删除、受限、验证未完成或正文无法解析时仍可能失败。

不收次幂接口费不等于没有网络开销或平台限制。仅获得目录，不能保证每篇都能免费取得正文。

## 方案二：免费订阅 · 微信读书

### 操作

1. 对标研究 → 选择公众号 → 连接与订阅设置（直达设置中心）。
2. 点击“打开微信读书登录”，在官方页面自行登录。
3. 返回点击“保存已登录的连接”。此时只表示会话保存成功，检查后才能验证可用性。
4. 新账号可从一篇原文免费识别发布账号；已绑定账号直接使用。
5. 设置检查间隔和是否自动保存正文，开启免费订阅；可立即检查、暂停或在停止后删除。

不要求手工复制 Cookie，也不会导入电脑微信的旧登录信息。程序不自动加入微信读书书架；目标账号可能未被收录或需要用户在微信读书自行关注。

### 运行原理与边界

本版参考 [we-mp-rss 的微信读书适配器](https://github.com/rachelos/we-mp-rss/blob/d8feb6a42c6773d7374e03c487d3ae3426084af8/core/wx/model/weread_mp.py)，独立实现列表获取、文章去重、正文读取及失败延后。上游的 [Webhook](https://github.com/rachelos/we-mp-rss/blob/d8feb6a42c6773d7374e03c487d3ae3426084af8/jobs/webhook.py) 是采集之后的通知，不是微信官方主动告知任意公众号发文。

默认每 60 分钟检查一次，可设置 30—1440 分钟。即使没有新文章也会访问免费来源，但不会因此调用次幂。发现延迟由上游收录时间、检查间隔和本地处理共同决定。

首次检查建立当前基线，不提醒旧文；后续新发现的文章进入本地目录和未读提醒，按设置自动补采正文。每轮最多 3 页目录、10 篇待补正文，保留补漏进度。正文失败与目录发现分别记录，避免正文失败导致重复新文提醒。

当完整列表不可用、只能从 cover 接口取得最新一篇时，显示“降级、可能漏文”。“本次返回结束”不证明公众号历史完整。登录失效暂停该用户的免费自动检查；网络和限流错误逐级延后，不能把程序限速当成平台安全频率承诺。

关闭工作台或休眠时不能持续检查。当前提醒在应用内，不包含公网 Webhook、微信消息或云端常驻服务。真实账号持续采集仍待验证。

## 方案三：次幂 API 手动备用

- [开通服务并获取 AppID / Secret](https://www.cimidata.com/api-service)
- [官方接口文档](https://www.showdoc.com.cn/2265380957870963)
- [官方报价](https://www.showdoc.com.cn/2265380957870963/11559023150418150)

在文章库的次幂设置或全局设置保存自己的 AppID / Secret。连接以加密形式保存在本机；认证测试不查询文章目录，但不能据此判断后续业务接口额度和覆盖率。

### 当前使用的接口

本版共使用 **4 类付费业务接口**，另有令牌认证。持续付费查询复用历史目录接口，不是第五种独立的发文推送接口。

| 接口 | 使用场景 | 参考费用 |
|---|---|---|
| `/api/v2/token` | 获取访问令牌 | ¥0，按官方报价 |
| `/api/v2/articles/info` | 从原文识别发布账号 | ¥0.02 / 次 |
| `/api/v2/articles/history` | 历史目录及付费定时检查 | ¥0.05 / 请求页 |
| `/api/v2/articles/long2short` | 付费正文需要的长链接转换 | ¥0.01 / 次 |
| `/api/v3/articles/detail` | 次幂正文补采 | ¥0.01 / 次 |

当前没有接入付费点赞、评论、阅读量等接口。后续调用 AI 分析正文属于模型服务费用，独立计算。

### 历史目录查询

先识别并核对公众号，填写开始/结束日期、标题关键词、篇数与本次页数上限，再确认查询。筛选在本地进行：未命中关键词或日期的目录页也可能产生费用。每次请求可能返回多篇，但不能固定承诺每页数量。

例如一次账号识别加最多 3 页目录，参考合计最多约 `0.02 + 3 × 0.05 = ¥0.17`。如果账号已绑定且本次只查询 3 页，参考目录费用最多约 ¥0.15；更改筛选后只查看已有本地库不增加次幂费用。

达到页数或篇数上限会显示部分目录，可从历史查询记录继续。续查是新的付费操作，需要再次确认。每次都会显示预计范围，取消确认不提交业务请求。

### 正文补采与缓存

免费获取不成功时，手动选择“次幂正文补采（计费）”。一批选择多篇，只弹出一次整批费用确认。

| 情况 | 参考成本 |
|---|---|
| 1 篇未缓存长链接 | 转换 ¥0.01 + 正文 ¥0.01，最多约 ¥0.02 |
| 10 篇均为未缓存长链接 | 最多约 ¥0.20，整批确认一次 |
| 已有可复用短链接 | 不重复转换；正文约 ¥0.01 / 篇 |
| 已保存且未删除的正文 | 直接复用，不重复调用付费正文 |
| 本地阅读或导出 | 不调用次幂 |

失败和超时不自动重试，因为请求可能已到达服务商并计费；工作台调用计数不等于服务商实际扣款账单。已经发生的费用不会因删除记录而退款。

### 付费定时查询

入口收在“手动选择备用：付费定时查询”中，只有用户明确开启后执行。开启或更改频率、上限，需要确认持续扣费规则；后台按已确认范围执行，不在每一次定时运行时重新弹窗。

没有新文章也可能收费。默认 120 分钟检查、每日自动调用上限 12 次、每轮最多 2 页；上限按当前用户所有公众号的自动目录调用合计，**12 次指接口请求，不是 12 轮**。按参考价计算，12 次目录请求约 ¥0.60 / 日，连续 30 天都用满约 ¥18；实际受运行时长、分页和每日额度影响。手动目录、账号识别和付费正文不包含在这个自动目录上限内。

开启免费订阅不会擅自关闭已有付费订阅。若只希望免费检查，应到付费区域手动暂停原付费任务。免费失败不会自动切换付费。

## 常见疑问

**为什么有 30 条目录，却只有 0 篇正文？**

目录查询与正文获取来自不同请求。正文可能遇到平台验证、失效或读取错误，应查看正文任务逐篇结果。

**能否完全免费并保证实时、完整？**

当前没有这样的已验证承诺。免费来源可以减少接口费，但仍受登录、上游收录、频率限制和接口变化影响。

**环境异常表示微信号已被封吗？**

不能仅从这个提示判断封号，也不能保证操作没有账号风险。完成官方验证、暂停采集或选择备用来源，由用户结合平台提示决定。

**目录导出含有什么？**

ZIP 包包含目录与已有正文；仅有链接的记录不会凭空生成全文。当前不是完整图片、视频离线归档。
