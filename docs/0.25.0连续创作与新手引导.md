# 0.25.0：连续创作与新手引导

保留已有深色工业风格，重点解决新手不知道下一步、页面跳转打断创作、技术参数过多的问题。

## 产品判断

目标用户是有行业经验、但未必熟悉 AI 的电梯经销商。用户需要回答三个业务问题：我是谁、今天讲什么、准备发到哪里。工具应承担身份引用、平台格式、生成参数与成果保存，让用户看到可以编辑、复制、下载的内容。

因此，“简单”应减少重复输入和无意义确认；“效果好”依靠真实 IP 信息、明确的平台写作方法、合适的素材与可编辑成品。单纯隐藏按钮或增加模板不能替代这些链路。

## 实际交互约定

- 未完成 IP 定位时，每次重新打开提醒；可稍后处理。已确认定位后停止提醒。仅有访谈草稿不算创建成功。
- IP 使用统一的 12 个问题及参考说明，AI 访谈逐题引导，保留进度；报告供用户核对，确认后才写入 IP 档案及其选题。
- 一站式创作保持步骤、平台、编辑区在同一工作区。身份选择、选题、各平台草稿、确认作品和发布准备共用同一作品身份。
- 公众号、小红书、朋友圈、短视频、数字人口播分别保留创作草稿；视频与数字人先准备对应脚本，再进入生成工具。
- 当前 IP 的选题直接展示，同时保留自由输入和完整选题库。
- 文稿修改后，传递到配音、数字人或加入作品前先保存，下一步使用最新保存版本。口播只使用可朗读正文。
- 看同行排在看行业前，行业内容在同页切换；添加信源使用当前页弹窗。服务、账号标识等技术配置收进设置。
- AI 视频按真实创作方式显示素材要求，首帧、首尾帧、编辑、延长的输入和校验各自匹配。模型与高级参数可展开调整。
- 首页保留对话、主要创作入口和继续任务，去掉重复示例与显眼的重复功能入口。
- 单张插图的 AI 提示词整理后直接采用；点击生成即提交，界面保留费用提示。状态未知时仍核查原任务，不重复新建付费请求。
- 公众号标题、作者和正文分别保存；作者可留空，AI 不覆盖手动署名。复制图文取正文，下载文稿包含标题与署名。
- 文章三图由用户主动启动，分别生成开头、中段、结尾配图。逐张保留任务编号，部分成功保留成果；正文发生后续编辑时不强行覆盖。切换账号暂停原批次，回到原账号继续核查。
- 小红书与朋友圈的图片作为独立素材保存顺序，支持选图、生成、排序和下载，正文不混入图片提示词。

## 数据如何联动

对话只是交互入口。IP、选题、文稿、素材、作品和平台草稿各有持久化记录与版本。

IP 档案提供创作身份与已确认事实；选题绑定对应 IP；每件作品保存所选身份、主题、各分支草稿与确认成品；平台草稿从这件作品选择的版本带入内容。独立对话成果需通过已有“用于作品”或导入操作明确归属，避免错误混入另一件作品。手动编辑保存在原稿版本中，生成记录不会被无提示覆盖。

保存、复制、下载、同步平台草稿与正式发布是不同动作。平台登录、真实接口可用性和实际发布结果按各自返回状态显示。

## 本次边界

保留知识库、历史成果与自由创作。界面与存储测试使用隔离环境；真实付费生成质量、平台授权和发布效果应单独验收。状态未知的请求不会自动重建，提示词请求完全丢失响应且未取得任务编号时保留待核查状态。
