# 0.14.0：创作平台与独立管理后台

## 使用入口

- 创作前台：桌面首页，按文案、图片、AI 视频、数字人、音频、视频合成分开操作。
- 管理后台：同一服务的 `/admin.html`，管理员在前台账户菜单打开，独立登录，不复用前台登录状态。普通账户即使直接请求管理接口也会被拒绝。
- 后台维护：模型连接、测试与上架、功能模型绑定、媒体 API、对标 API、提示词、上传 Skills、用户启停与操作记录。
- 个人偏好：只保留当前设备的显示偏好、软件版本与更新，不放共享 API 配置。

这里完成的是独立前端构建入口与服务端权限分离。当前仍运行本机 FastAPI 服务，没有擅自改为联网 SaaS，也没有部署远程管理后台。多个经销商共享的企业组织、授权销售、支付和平台账户计费不是本次本地版本已完成的能力。

## 创作流程

1. 在“品牌与 IP”填写业务事实；手动建立 IP，或让模型生成定位候选，核对后确认。
2. 文案选择品牌、IP 和本次参考资料，生成后编辑、保存或下载。不会自动检索或沉淀个人记忆。
3. 文稿可传递到文字口播、配音；图片可传递到图生视频；媒体可传递到视频合成。
4. 草稿自动存入数据库，并有本机临时草稿兜底。服务端版本冲突不会直接覆盖。
5. 每次生成保存独立任务和草稿版本；作品进入“我的作品”，媒体进入“我的素材”。导出不代表发布。

品牌事实、IP 表达定位、数字人形象和声音是不同对象。品牌/IP 在媒体任务中用于归属记录，不会自动训练形象或声音，也不会自动改写已确认的口播稿。

## 核心能力与接口边界

| 页面 | 已接入的核心操作 | 服务 |
|---|---|---|
| 文案创作 | 参考资料、品牌/IP、生成、编辑、保存、下载、转口播/配音 | 管理员绑定的文本模型 |
| 图片创作 | 文生图、参考图编辑、尺寸等接口支持选项 | 阿里云百炼 |
| AI 视频 | 文生视频、图生视频；参数按接口能力展示 | 阿里云百炼 |
| 数字人 | 文字口播、音频驱动口播、照片说话、创建图片/视频形象、公共/个人形象库 | 飞影 |
| 音频 | 文本配音、创建声音、声音库 | 飞影 |
| 视频合成 | 场景顺序、画面素材、时长、配音、字幕与原声音量 | Shotstack |
| 灵感与对标 | 账号识别、限定数量/请求预算获取、真实文字分析、转文案参考 | TikHub；公众号另支持次幂 |

音频口播不需要另选声音。照片说话使用图片、文字和声音，不假定支持录音驱动。素材成片需要已有画面，单独传入配音时还必须选择图片或视频。公共形象/声音库当前按供应商返回的首批资源展示，不声称完整目录。

双人播客、产品互动、唱歌、直播、多页图文和复杂视频续写保留为后续能力，不把普通视频参数挪用为这些功能。

## API 配置

| 服务 | 后台配置 | 官方资料 |
|---|---|---|
| 飞影 | API Key、官方根地址、启停 | [API 文档](https://api.hifly.cc/hifly.html) |
| 阿里云百炼 | API Key、官方根地址、启停 | [百炼文档](https://help.aliyun.com/zh/model-studio/) |
| Shotstack | API Key、沙盒/正式环境、启停 | [API 文档](https://shotstack.io/docs/api/) |
| TikHub | API Key | [官方 SDK 接口参考](https://github.com/TikHub/TikHub-API-Python-SDK/blob/main/docs/reference.md) |
| 次幂 | App ID、App Secret | 后台提供服务方入口 |

密钥由服务端加密保存，读取设置不返回明文。普通页面仅显示是否配置。没有配置就禁用提交，不以示例图片或虚构任务代替生成结果。

飞影文档的 TTS 接口返回任务编号，但统一 `/video/task` 查询说明未显式列出音频类型。本版按已公开接口适配，不编造 `/audio/task`；**实际音频任务返回格式仍需真实账号核验**。配置完成也不等于账号套餐、所有素材格式和接口都已经实测。

## 对标数据的真实边界

“获取数量”是应用的目标上限；系统按供应商分页参数逐页请求，再按目标数量与请求次数预算停止。视频号等接口没有相同的 count 参数，不能直接当作统一接口。

列表结束、预算耗尽、字段缺失和部分失败分别记录。发布日期缺失的作品不能假装符合日期范围；发布文案不是口播转写。对标分析只使用已拿到的文字，不推断视频画面，不声称覆盖全账号历史。

## 异步任务与数据

- 同一请求编号重试返回原任务，执行中的相同草稿版本不重复提交。
- 提交结果不确定时保留 `unknown`，不自动新建付费任务。
- 服务重启后有任务编号的继续查询原任务；结果已生成但下载失败的只重试下载。
- 输出保存到本机后才显示归档成功。播放、下载需要当前用户权限。
- 原有数据库、用户目录、模型配置和历史文稿保留；自动知识整理默认停止。
- 便携 ZIP 备份补上媒体和新对象，恢复时重映射素材/品牌引用；不恢复远端任务执行权、供应商密钥或私有云资源授权。便携备份媒体上限95MB、压缩包上限100MB，大文件请从作品库单独下载保存。

## 桌面升级

参考 AI 电商桌面产品的流程，采用 `electron-updater`：检查版本、下载进度、完整性验证、失败重试、用户主动确认安装。关闭自动下载、自动退出安装和降级。

源码运行版显示开发状态；没有正式 `app-update.yml` 时显示更新渠道未配置。本次未发布更新服务器、未上传 Release、未配置签名证书，也未执行远程升级。正式更新应由发布流程生成更新元数据，先完成签名、渠道和旧版到新版的更新验收。[Electron Builder 更新文档](https://www.electron.build/v26/docs/features/auto-update/)

## 验证口径

- 本地构建：前台与后台分别生成 HTML 入口。
- 后端：回归、持久化、越权、版本冲突、接口参数、异步恢复和媒体备份测试。
- UI：隔离 Electron 环境验证所有核心页面、品牌保存、文案生成编辑、对标传递、前后台登录隔离。
- 真实文本模型：使用已授权的既有 CPA 配置，只读读取配置，在独立测试数据目录验证文案与 IP 生成/确认。
- 真实媒体和对标付费请求：未执行；测试响应只在测试环境使用。
- 本地打包与安装文件校验单独报告，不能替代商业云部署和供应商实测。
