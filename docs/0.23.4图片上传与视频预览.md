# 0.23.4 图片上传、编辑切换与视频预览

正常 JPEG 原样保存；图片扩展名与编码不一致时按内容识别。大图自动适配为最长边不超过 4096、文件不超过 10 MiB 的创作版本，校正照片方向，保留透明通道和原始文件。两个上传入口均显示处理结果，素材库下载原文件。备份包含原图，并校验总容量与恢复后的私有下载地址。

常用独立编辑页及仅含 mode 参数的页签保留编辑状态，最多六页；默认 mode 与无参数地址共用实例。账号或工作区变化清空保留状态。指定草稿、来源任务、作品与资源返回仍先验证范围；更新后的本机草稿同时维护 latest 别名，按已授权的草稿编号恢复，防止快速切换丢失修改或覆盖其他草稿。

首页、素材库、生成结果和参考素材共用视频放大查看，保留位置、音量、静音、倍速和播放状态。数字人素材预览也同步播放设置。关闭或跳转时清理弹窗，关闭后恢复触发按钮焦点。桌面原生全屏仅向工作台自身页面放行；其他权限继续拒绝。修正数字人错误提示及返回栏残留的浅色背景。

## 验证

- 实际安装的旧版 0.23.3：正常 JPEG 200；PNG 编码的 JPG、48MP JPEG 均 400；原生全屏未开启。
- 实际打包的 0.23.4：上述三类图片均 200；48MP 图片适配为 4096 × 3072；下载原文件与输入字节一致；原生全屏成功。
- 新增上传回归 10 项：原样质量、真实编码、方向、透明通道、像素安全边界、文件大小、损坏文件清理、解码并发限制、跨账户原图访问与备份恢复。
- 后端相关回归分别通过 61 项、52 项；数字人既有界面回归 10 项及四种配色状态通过。
- 新增真实页面检查：两个上传入口、提示、等价地址、快速返回指定草稿、保留声音选择、阻止外来草稿、真实 H.264 解码与放大/全屏/退出/焦点/设置同步。已打开的数字人页切回约 32ms，重复草稿/目录读取为零。
- 实际打包程序的知识检索、媒体目录、系统能力、官方视频参数和桌面桥检查通过。
- 对抗审查两轴发现的原图备份、内存并发、重复编辑实例、资源返回后的快速切换问题已修复并复核。

## 边界

一亿像素以上或损坏、无法解码的图片明确拒绝。大型图片解码占用单个处理槽，忙时提示重试，避免多图同时占满后端内存。合适大小的正常图片不重编码；原图不裁切、不覆盖。首次打开和需重新验证来源的页面仍要读取真实数据。

本次没有拿到截图中的两张 JPG 原文件，不能断定它们具体属于哪种失败原因；已在旧安装版复现相同报错路径，并在新打包版验证对应修复。未调用付费数字人或图片生成服务。
