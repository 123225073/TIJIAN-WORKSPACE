# 0.30.0 上线检查与修复

本轮以现有桌面版的排版、可读性和主要操作稳定性为目标。管理员首次创建、云端用户管理和云服务器部署留待后续实施。

## 首页对话

- 空白点击“开始对话”进入独立的新聊天，输入框保持空白，不插入空消息，也不调用模型。
- 输入问题后，提交确认成功再进入聊天；相同问题也能建立新的对话，不再悄悄复用历史问答。
- 首页切页、刷新后恢复未发送的问题。中文输入法确认文字不会误触发送。
- 提交失败或提交后的读取失败会留下可见提示并保留输入；服务已接收但浏览器丢失响应时，再次点击恢复原对话，避免重复提交。
- 创建时不再等待整库刷新；用户已转到别处时，迟到响应不会把页面强行切回。
- 新空白聊天在实际发送第一条消息后更新标题；长问题完整保留，任务标题只作摘要。
- 知识助手采用相同的提交后跳转、个人模型偏好识别和问题保留行为。工作区首次读取失败可点击重新连接。
