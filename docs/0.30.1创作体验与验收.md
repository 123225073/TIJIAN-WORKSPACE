# 0.30.1 创作体验与验收

## 本次变化

- 数字人结果页提供默认收起的模板与字幕合成。三套样式支持标题和 SRT 字幕；本机 FFmpeg 另存成片，原视频保留。成片可预览、放大、下载并选入一站式作品。字幕需要导入或编辑有时间轴的 SRT，本版没有自动识别服务；已烧录字幕的原片应避免重复添加。
- 数字人口播使用纯文字编辑界面，文稿名称不参与朗读；进入制作页面后可以返回同一份文案。生成标题不再使用附加的内部口播规则。新稿明确标注的正文首行标题会与独立标题统一；旧稿发生冲突时由用户选择，程序不静默改写。
- 图片生成的“模型与尺寸”入口紧邻创作标题，图片编辑也保留设置入口。小红书当前稿件可将文案及顺序配图打包下载，缺图或版本变化时明确拒绝生成不完整包。
- 小红书一键配图根据封面、内页、结尾分工组织提示词；短视频按对镜口语重新组织。来源、方法及限制见《小红书配图与口播方法研究-2026-10-28.md》。

## 验证

- 前端生产构建通过。60 项相关后端测试通过；数字人成片补充了 2:3、9:16、16:9 的真实 FFmpeg 渲染检查。
- 一站式创作隔离界面回归 8 项、图片创作与编辑界面回归 16 项、文案转交返回回归 4 项通过。模型请求在这些测试中被拦截，没有付费调用。
- 数字人隔离界面使用本地测试视频实际合成；原片和成片放大、下载，成片选入当前作品，原文件哈希不变。打包后端使用随包 FFmpeg 再次生成含中文字幕的成片，保留音轨、时长和尺寸，抽帧确认中文正常。测试素材为合成样片，不是真实飞影视频。
- 安装器退出码 0，安装后六项程序与资源哈希与已验收的打包目录一致；桌面快捷方式启动新版通过。升级前数据库备份位于 `.runtime/upgrade-0.30.1/`，升级后完整性正常，13 张表的记录数量与基线一致。
- 未做真实付费模型生成和生图质量验收、真实飞影视频验收、对外发布或云部署。独立生成的多张图不保证文字完全准确或风格完全一致。
