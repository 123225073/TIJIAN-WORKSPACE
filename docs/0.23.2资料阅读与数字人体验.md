# 0.23.2 资料阅读与数字人创建

## 本轮优化

- 延续首页已认可的黑曜石、浅色文字与克制蓝金风格。雷达阅读底部、Wiki/记忆历史、数字人说明和提示区使用深色界面背景。
- 知识库五类信息平铺。文件夹、检索列表与阅读区采用连续布局；搜索与全选集中在列表顶端，条目显示两行标题、状态与日期，编辑/删除保持可见。
- 长正文保留舒适字号与行距。桌面布局和窄窗口分别采用并排/上下排版，标题不撑宽页面。
- 飞影数字人按素材要求、创建方式、形象名称、人物素材、生成设置分组。名称只显示一个输入；使用原草稿字段，历史兼容。
- 人物照片与视频增加“放大预览”；视频保持原生播放控件，不自动播放。支持 Esc/关闭、焦点返回及切换素材时关闭旧预览。图片不会重复打开全局灯箱。
- 任务仍异步处理；身份默认值、素材互斥、草稿归属与恢复规则保持。
