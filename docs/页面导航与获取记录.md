# 页面导航与获取记录

适用版本：0.6.0。

## 页面分工

日常页面回答三个问题：这里有哪些内容、当前处理到哪里、下一步可以做什么。登录连接、接口密钥、定时频率和默认偏好集中在左侧的「设置中心」。无需为了阅读文章先浏览一整页配置。

| 日常入口 | 核心信息 | 配置入口 |
|---|---|---|
| 今日工作 | 工作目标、最近任务、待办 | 全局设置中心 |
| 行业雷达 | 已取得资讯、平台热榜、来源状态 | 信源设置：地址、启停、添加与修改 |
| 对标研究 | 已保存正文、订阅发现、手动获取、获取记录 | 当前账号的连接与订阅设置 |
| 内容中心 | 稿件、状态、排期 | 模型与创作偏好 |
| 我的 IP | 定位、受众、渠道等业务资料 | 平台连接放入设置中心，身份资料仍在本页维护 |
| 知识资产 | 原始资料、已确认知识、待办与冲突 | 存储与备份设置 |
| 数据复盘 | 实际发布与表现数据 | 平台连接放入设置中心；观察日期和指标是业务输入，保留本页 |
| 资料管理 | 检索、编辑、回收站及恢复 | 连接配置不放在资料列表 |
| 任务中心 | 执行状态、结果、时间与取消／重试 | 不在结果里编辑连接参数 |

## 对标研究怎么使用

1. 选择左侧关注账号。页面上方显示账号、正文数量及微信读书运行状态。
2. 默认进入「已保存正文」，标题是主信息。可以搜索、按获取方式筛选、阅读、编辑、删除或带入分析。
3. 「订阅发现」呈现通过订阅渠道发现的目录。其中自动调度与用户主动检查分别标记。未读新发现可标为已读；缺少正文时可以选中补采。
4. 「手动获取」提供三个明确入口：粘贴文章链接、导入已有文稿、从目录选择文章。只有选中第三个入口才展开历史查询、日期筛选、目录分页与正文采集。
5. 「获取记录」按任务显示触发方式、提交／开始／结束时间和逐篇结果。删除记录不会删除已保存正文。

目录每页显示 20 篇，支持跨页勾选（每批最多 100 篇）；「选择本页」会将选择替换为当前页，单条勾选可以跨页累积。付费补采按最终已选数量确认整批预计费用，不逐篇确认。取消确认不会调用付费接口。

自动发现的文章即使保存了正文，仍可在订阅发现中追溯；已保存正文汇集所有来源成功取得的内容。两者是同一份文章的不同阶段，不复制正文、不重复计费。

## 设置中心的六个模块

- **工作区与数据**：保存位置、备份导入／导出、Obsidian 文件变化检查、保留策略说明。
- **AI 与创作偏好**：各工作类型的可用模型和提示词偏好；管理员可继续进入模型服务、验证、上架和默认绑定管理。
- **对标与订阅**：选择账号、修改资料、微信读书登录与连接、免费检查频率、自动正文保存、付费轮询备用。
- **次幂服务**：AppID／Secret 加密保存、认证检查、获取凭据链接、接口文档和官方报价。
- **雷达信源**：来源地址、最近成功／错误、启用与暂停、添加／修改／删除。
- **平台账号**：原有的独立平台登录及账号管理。

业务页上的链接直接进入相应模块。对标设置页提供「返回对标研究」，带回原账号和页签；当前会话中保存正文的搜索、来源筛选及目录日期／关键词条件会保留。用户凭据不保存在这些界面状态中。

## 连接状态怎么理解

「连接已保存」仅表示会话已存入本机，不表示接口已验证成功。业务页会区分尚未连接、未开启、等待首次检查、运行中、暂停、需要重新登录、检查异常、仅能发现最新一篇等状态。

登录失效时，业务页显示异常和直达重新登录的链接，不再展示一个会继续正常执行的下次检查时间。重新登录由用户在平台窗口操作；免费失败不会自动切换付费。已开启的付费备用会另外显示。

「立即免费检查」是业务操作，保留在对标页；频率和自动保存规则是后台配置，放在设置中心。

## 来源和时间的准确含义

| 字段 | 含义 |
|---|---|
| 发布日期 | 来源平台提供或用户导入时填写的文章日期；缺少依据显示未知 |
| 目录来源 | 首次进入目录时由自动订阅、手动检查订阅或手动目录查询触发 |
| 正文获取方式 | 自动订阅、手动检查订阅、目录采集、手动链接、手动导入 |
| 获取服务 | 微信读书、公开页面、次幂或本地文稿；与触发方式分别保存 |
| 首次发现时间 | 第一次取得该目录条目的服务端时间；重复发现不会覆盖 |
| 正文保存时间 | 正文首次写入资料库的服务端时间；复用已有正文不会覆盖 |
| 最近尝试时间 | 最近尝试读取正文的时间，不代表该次成功 |
| 任务开始／结束 | 任务实际执行及结束的时间；提交时间单独保留 |

数据库记录为 UTC 时间，界面按本机时区显示完整日期、小时、分钟和秒。一般列表先显示标题及简短来源，点击「获取时间」展开详细时间。

旧记录没有这些字段时显示「历史记录 · 来源未细分」或「未记录」。不能用最后编辑时间推算首次保存时间，也不能仅凭微信读书来源推断过去是自动调度还是手动检查。

本次界面调整不改变上游采集权限。微信读书仍受登录、收录、列表降级和平台限制影响；这里只准确呈现其状态，不承诺实时推送或完整历史。
