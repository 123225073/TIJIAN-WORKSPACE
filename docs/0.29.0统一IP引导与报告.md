# 0.29.0 统一 IP 引导与报告

“我的 IP”新增、首页首次提醒和 Agent 对话中的定位请求，现在进入同一个独立引导页面。页面依次显示沟通定位、生成报告、确认保存三个步骤。十二题的顺序和事实边界保持一致，不清楚的内容可以标为待确认。

回答自动保存；刷新、返回或重新进入会恢复进度。最后一题保存后自动整理报告。报告以大标题、八个章节和正文呈现，回答记录及摘要修改默认折叠。原 Agent 对话作为背景保存，不会被自动当成已确认答案。

核对报告后确认，才建立或更新 IP，并关联相应的选题建议和原对话。更新已有 IP 时明确显示目标档案名称。旧档案、问卷回答和独立扩展字段保留，尚无报告的档案可通过 Agent 引导完善。

首次提醒采用与工作台一致的深色背景和清晰按钮，支持键盘焦点循环及 Esc 关闭。报告主标题只显示一次，章节与正文有明确层级，窄屏支持纵向阅读。

异常恢复覆盖：回答保存成功但响应丢失时，不把旧回答带入下一题；修改回答后旧报告失效；原对话或参考身份变化后，可以重新整理报告再确认；确认期间离开页面，完成后不会抢回当前页面。服务端保留版本校验，防止旧报告覆盖已修改档案，确认写入采用同一数据库事务。
