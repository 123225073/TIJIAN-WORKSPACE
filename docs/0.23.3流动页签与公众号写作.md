# 0.23.3 流动页签与公众号写作

- 横向同类页签使用统一流动高亮和水滴边缘形变，覆盖主工作区、知识库、后台、文稿视图和配图弹窗。原导航、按钮语义和焦点保持；减少动画偏好生效。
- 对话成果的参考资料与版本区域、素材历史和等待区、封面占位、图片留白及滚动条统一深色。正文纸张和手工颜色独立保留。
- 图片比例和分辨率分别设置，可选择2:3、9:16及1K/2K/4K，也可输入2.32:1。按模型公布选项采用最近值，记录用户意图和实际提交值，生成后提示。
- 仅在已确认媒体任务遇到明确HTTP400/422尺寸拒绝时尝试一次最近可用尺寸；认证错误、超时、不确定提交、已有任务/结果字段不自动重试。
- 对话图片和配图大预览直接读取原图，列表继续使用轻量缩略图。清晰显示不能增加原文件本身的像素。
- 公众号叙事、标题和封面方法接入内置全局Skills，遵循管理员编辑/停用状态。已有成稿不会自动重写。来源与筛选见[写作方法说明](公众号写作Skills筛选与内置方法.md)。
