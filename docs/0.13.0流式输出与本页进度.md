# 0.13.0：流式输出与本页进度

本次保留现有业务流程，解决定稿阻碍、服务列表过长、生成等待和反馈不明确的问题。

## 使用变化

- **确认定稿**：保存正文后即可定稿，移除事实核查页签、按钮和强制条件。定稿表示用户采用这一版；不会声称内容已被独立核实。再次编辑后恢复草稿，历史版本保留。
- **平台目录**：管理后台左侧选择服务平台，右侧只展示该平台的配置和模型；搜索、发现模型、测试、上架均针对当前平台。DeepSeek 默认入口及 API 获取链接保留。
- **流式文字**：对话、文章、工作成果、定位与知识整理统一使用流式模型调用；页面持续显示已收到的文字。结构化整理仅展示面向用户的文字字段，不展示内部字段或推理过程。
- **就地反馈**：模型测试的进行中、成功回复和失败原因直接显示在模型行内；发现模型在当前平台显示结果。对话、成果、知识提炼、配图在各自操作区域显示进度，其余接口操作在当前页面显示状态。任务中心保留为历史记录入口。
- **中断保护**：取消或连接中断不把部分生成内容当成完整成果保存；已保存正文与人工修改保留。等待期间可停止任务，离开后返回仍可查看后台进度。

## 实际边界

文字支持 Chat Completions 与 Responses 的 SSE 响应；若兼容服务忽略流式参数而返回整段 JSON，会明确提示该服务未返回流式数据，不做假打字动画，也不重复发起收费请求。思考模型在首段正文前可能仍需等待。

图片仍按所配置生图接口返回完整图片，界面显示实际阶段和耗时，完成后展示预览；不编造百分比或假装图片支持逐块生成。

旧版核查数据保留以兼容历史备份；当前界面与定稿流程不再使用核查功能。

## 验证

- 144 项后端测试通过，覆盖两种流式协议、提前断流、取消、非流式服务提示、进度访问隔离、定稿和编辑。
- 桌面页面测试覆盖首段文字先于完整消息出现、成果整理预览、直接定稿、10 个平台切换、模型测试成功与失败在行内显示。
- 真实 gpt-5.5 调用接收 215 个文字片段，约 3.6 秒出现首段、6.5 秒完成；这是一次实测数据，不代表所有模型的固定响应速度。

模型凭据、用户资料和测试产物不上传 GitHub。
