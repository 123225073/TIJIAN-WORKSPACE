# 梯世界 0.22.0：视觉、创作路径与加载优化

## 用户需求与取舍

这次重做解决三个问题：页面之间的视觉割裂、复杂创作过程难以理解、不同操作习惯之间意外共享草稿。视觉效果必须帮助用户辨认内容和状态，不能让透明效果降低阅读对比度，也不能让动画成为新的加载负担。

- 导航、工具卡片、对话、素材和后台采用深色金属底色、冰蓝强调、少量香槟金与局部玻璃效果。
- 标题和辅助文字提高对比度，使用本机字体，不再等待远程字体服务。全页没有持续动画或大范围模糊效果。
- 长文编辑、文章预览与图片替换预览使用独立纸张样式。系统界面颜色不能覆盖正文格式；人工设置的文字颜色保留。
- 首页保留“抢占线上曝光，用户一搜即见。”，明确提供 AI 对话与一站式创作两个入口。

## 两种独立操作方式

| 方式 | 主要操作 | 成果归属 | 引用方式 |
|---|---|---|---|
| AI 对话 | 在同一个对话中提出写作或媒体需求 | 对话自己的平台稿、媒体方案与生成记录 | 明确选择资料或现有成果 |
| 一站式创作 | 按纵向步骤完成一件作品 | 当前流程自己的草稿、作品与平台准备稿 | “导入现有成果”创建本流程副本 |
| 独立创作工具 | 直接打开文案、图片、视频等工具 | 独立工具自己的草稿 | 用户手动选取素材 |

不同对话、不同流程和独立工具不会自动恢复彼此的最近稿件。每份流程有稳定作品编号；文案和媒体草稿通过专属接口保存，普通接口不能改写归属。共享选题、原始资料和身份不等于共享可编辑成果。

导入保留原记录、原版本和引用来源；复制后的修改只作用于当前流程。旧版流程已有的关联会保留或转换为本流程副本，原始资料不删除。

## 纵向一站式工作流

从上到下展示“方向与身份 → 选好主题 → 内容分支 → 确认作品 → 平台准备”。左侧保留步骤连线、状态、已选主题与成品概览，右侧编辑当前步骤；可随时返回，恢复未完成草稿。

内容分支覆盖文案、图片、视频、数字人口播、配音、素材成片。平台准备沿用当前支持的公众号、视频号和抖音；AI 对话保留公众号、朋友圈、小红书、视频号和抖音独立成果。平台准备、导出和生成均不等于公开发布。

## 加载瓶颈与实测

原先首屏等待整库历史读取；数据库里约 87 MB 内联图像虽然不会对外返回，却先进入了复制、排序与解码过程。模型目录还会重复读取配置，空闲页面会周期性刷新完整状态。

改为轻量首屏、历史后台补齐、当前对话关联对象定向同步、并发读取去重、写后补读、只读 SQLite 快照和 SQL 提前排除不需要的内联图像。媒体历史保留原有数量、状态和任务信息，保存数据不改变。

同一份 504 条记录的隔离数据库副本，每项 7 次测量，中位数如下。未运行该副本的夜间整理、订阅或真实供应商调用。

| 接口 | 改前 | 集成后 |
|---|---:|---:|
| 首屏所需状态 | 完整历史 1.80 MB / 928 ms | 轻量状态 15.9 KB / 7.36 ms |
| 完整历史 `/state` | 928 ms | 282 ms |
| 模型目录 | 612 ms | 103 ms |
| 媒体生成历史 | 629 ms | 214 ms |

这组数字是本机 API 测量，不代表真实供应商生成速度或所有电脑的端到端时间。另在暂停完整历史请求的页面测试中，首页输入区仍可使用；输入、旧任务路由及知识正文在恢复后保持。
