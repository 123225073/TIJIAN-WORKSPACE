# 0.27.0 平台素材管理与工具布局

## 发布准备

同一个选题按公众号、小红书、朋友圈、短视频、数字人口播切换查看。每个平台可以选取已保存的稿件，每次只展示该稿关联的图片，避免不同选题、不同版本重复混排。图片按稿内顺序编号，支持单张下载、滚轮缩放预览，以及一键下载本稿全部图片的 ZIP。

归属依据是已保存的生成任务、草稿或发布稿关联。无法确认选题的旧稿和其他选题的内容保留在“找回历史与未归类素材”，不修改历史资料。外链图片须先导入本地；缺失或无权读取的图片会明确提示，并停止不完整 ZIP。稿件已更新时，旧版本下载链接提示刷新。

## 更多制作工具

内嵌图片创作修正为输入区、拖拽条、结果区三列；窄区域自动上下排布。图片编辑画布、文本配音、素材成片按内嵌容器宽度适配。模式、参数和提示词操作按钮保持可读，素材成片场景卡使用配套的深色背景及文字。

## 素材成片的真实能力

该功能把已有图片、视频、音频和字幕按场景顺序编排，再调用 Shotstack Ingest 和 Render API 合成 MP4。它不是本地 FFmpeg 剪辑入口；需要后台配置 Shotstack 服务。未配置时可以编排、保存草稿，不能开始合成。提交时所选素材会上传云端，按服务账户的规则计费。本次未调用付费生成服务或公开发布内容。

## 验证

本版新增接口 12 项、既有工作流与媒体回归 55 项通过；组件验收 8 项、最终生产前端与真实后端交互 4 项、更多工具多尺寸组合 16 项通过。前端构建通过。验证清单与发布记录在本机交付报告中保留。隔离测试使用真实后端、SQLite、上传 PNG 和实际 ZIP 文件；测试种子明确标为隔离数据，不冒充真实模型生成。验证平台与稿件切换、历史隔离、单图和 ZIP 字节一致性、缩放与刷新，并核对多窗口尺寸的工具布局。真实 Shotstack 合成仍取决于服务配置及用户实际使用。
