# 小红书配图与口播方法研究

本次公开资料检索用于改进既有流程的提示词，不执行或安装来源项目的代码，也不将仓库热度等同于内容效果。

- [Ian XHS Carousel](https://github.com/helloianneo/ian-xhs-carousel)：提供封面、步骤、对比、清单、结尾等不同页面母版，强调每页一个重点、少字和统一风格；原项目采用先分镜后渲染的流程。本项目只参考这些设计原则，保留既有图片模型生成方式，并非接入其渲染器。
- [短视频口播文案 Skill](https://github.com/yinsheng508-byte/short-video-skill/blob/main/references/short-video-script.md)：区分完整创作、润色与素材整合，并强调观点、逻辑推进和口语节奏。未确认该仓库复用许可，因此不复制其文本或代码；本项目独立表达适合电梯行业的通用写作原则，不照搬缺乏依据的效果判断、虚构案例或固定情绪套路。
- [小红书图文 Skills](https://github.com/FJ900817/xiaohongshu-skills)：将文字、视觉及核验分开。项目继续保留用户编辑、预览和下载流程，不引入其发布或账号操作。

一键配图仍然逐张调用模型：提示词要求按封面、不同内页和结尾分工，但实际内容和文字准确性取决于模型，无法保证图片完全一致、无重复或达到“爆款”。口播适配在已启用短视频方法时用于视频平台，管理员停用该方法时不重新注入；不改变其他平台格式。真实模型生成仍需人工核对事实和可读性。
