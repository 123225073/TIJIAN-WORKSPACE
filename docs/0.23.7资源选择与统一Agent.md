# 0.23.7 资源选择与统一 Agent

## 本版修复

- 原稿选择入口先保存草稿，携带服务端草稿编号；资源库返回时读取并更新同一原稿，再回到编辑器。清空本机缓存、刷新页面、从一站式或对话进入时，保留文稿、IP、音频及原来的创作范围；版本冲突不会强制覆盖。
- 形象和声音按“我的 / 公共 / 全部”资源文件夹显示，默认先显示个人资产。表单选择也按个人与公共分组，可在表单或资源库设置、取消默认值；新的草稿采用有效默认值，不覆盖已有原稿的选择。
- 默认值按用户及飞影服务账号隔离；已归档、不可用、其他账号或不兼容的资源不作为有效默认值。
- 我的 IP 展示个人创建的形象和声音，支持照片预览、视频播放与放大、录音试听；公共和已归档资源不混入个人资产。
- 工作成果、参考资料、版本共用固定的工作区宽度、列宽和滚动边界，切换页签不会随内容长度收缩。
- 后台增加“统一 Agent”基础提示词；原有专业提示词作为任务方法保留。对话和文案工具共用写作请求组合，加入平台、字数、IP、资料及原稿，保留配置版本和输入哈希。详见 [调用说明](统一Agent与写作方法调用说明.md)。

## 公共样片的实际限制

2026-10-09 对已配置飞影账号的只读查询确认：公共形象的行仅返回 `avatar / kind / title`，声音返回 `voice / type / title / pitch / rate / volume`，没有封面、视频或试听地址。官方网页有自己的样片字段，但未发现能与 v2 列表准确关联的标识，不能按同名猜配。

本版保留供应商实际提供的媒体字段，并通过授权预览接口加载、隐藏签名地址；没有样片地址的资源明确说明原因，提供 [飞影形象库](https://hifly.cc/market/digital) 或 [声音库](https://hifly.cc/market/voice) 入口。这不等于所有公共资源已经能在本软件直接播放，完整内嵌样片仍依赖飞影提供可关联的媒体信息。

已创建形象的“创建原视频 / 原照片”用于核对出镜素材，不伪装成新的驱动成片。播放本地素材、选择、设置默认值和预览配置不会提交新的生成任务。飞影积分说明沿用 [费用核对记录](0.23.6形象预览与费用说明.md)，未得到精确的当前 API 单价，不能承诺克隆免费。
