# 0.32.7 小红书统一配图验收

小红书使用与其他文章平台相同的 ArticleImageRail：直接选择比例、数量、图片参考风格，生成图片先保留在右侧，由用户单张、整组或 AI 安排插入。移除旧小红书面板的独立一键配图入口。新批次默认 16:9；旧批次保留冻结参数和原请求标识，继续恢复，不重新生成。小红书专属文案写作规则保持原有实现。

## 已验证

- TypeScript 检查与生产前端构建通过。
- 文章配图区 11 项隔离浏览器检查通过，包括旧社交批次恢复、原请求不重复提交、保留旧图、生成后不自动插入、整组插入与失败重试。
- 内容矩阵真实本地后端及隔离 SQLite 检查通过：三个平台独立文稿；小红书显示统一配图区、没有旧入口；图片上传后正文不自动变化，主动插入并保存后重新打开仍可显示。
- 多平台批量配图预检查、原任务阻挡与清单恢复检查通过。
- 实际打包 Electron 检查通过，包含小红书统一配图区与默认比例，以及文章保存、导航折叠、图片风格与任务进度交互。
- 安装至原位置后版本为 0.32.7.0，桌面快捷方式启动健康接口返回 0.32.7；程序、前端、后端及媒体组件共六项文件与验收包散列一致。
- 升级前数据库备份与升级后实际数据库逐项比较：120 份创作草稿、78 条生成记录、129 项素材、42 篇内容、49 份文字草稿、62 个选题，以及作品、账号、历史和 32 项配置均保留；SQLite 完整性通过。

## 验证范围

模型生成场景使用本地接口替身，数据保存在隔离目录；未调用收费模型或提交真实平台发布。既有数据保留通过实际安装数据库验证。发布附件与本地产物清理由对应发布、校验及清理记录确认。
