# 0.23.10 数字人与声音资产命名

- 创建声音增加独立的声音名称输入；名称自动保存，未填写时不能提交克隆。
- 自己创建的数字人和声音，在选择弹窗、资产库、我的 IP、创建结果里均可改名。卡片先显示名称，再提供预览／试听。
- 改名立即同步到当前页面及选择框，刷新后仍保留。已选资产和默认项按编号引用，改名不改变素材、声音参数或已有文稿。
- 改名只修改本机的资产标签，不请求飞影重新克隆或重新生成，公共声音名称保持只读。
- 并发改名会检查版本，提示最新名称并保留尚未保存的输入；不会用旧窗口覆盖其他窗口的更新。
- 选择弹窗中的声音播放器限制在卡片宽度内，名称及改名按钮采用统一深色样式。

相关接口：`PATCH /api/studio/assets/{id}` 只接受 title 和 version，校验归属、名称长度、资产类型及版本；保留修改历史。
