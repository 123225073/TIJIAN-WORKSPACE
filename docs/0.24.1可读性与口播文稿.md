# 0.24.1 · 可读性与口播文稿

沿用现有深色工作台的字体、导航与配色，只修复操作选项和有问题的界面。

- IP 写入方式分为并列的“新增 IP”和“更新已有 IP”。新增建立独立档案；更新选项内选择具体目标。改变方式或目标后，先重新整理、核对，再确认写入，避免把旧候选写到错误档案。
- 已保存 IP 卡片的访谈与编辑按钮采用深底浅字；配图弹窗的候选提示词、确认区、预览区、加载与禁用状态沿用深色面板。标题独立于滚动区。
- 平台交付中的选题摘要、发布表单、视频选择、帮助说明与公众号连接状态统一修正对比度。文章的白色纸张和用户选择的文字颜色保留。
- 一站式创作带入口播或配音时，优先读取明确的朗读正文；历史文章清理文档标题、Markdown 和明确的制作标记。原文不被覆盖，已经手工编辑的媒体草稿与发布稿也不被自动重写。
- 文章如果还需要调整为适合说话的表达，可以使用现有文案创作入口“改写为口播稿”，核对生成结果后选入作品。跳转和格式清理不会自动调用收费模型。

验证采用真实组件与隔离数据库，覆盖选项切换、实际创建与更新请求、正文传递、配图插入、弹窗滚动、预览、确认、禁用、错误、关闭恢复和平台表单状态。模拟模型与图片只验证交互和数据链，不代表真实付费生成质量。

本轮完成相关后端回归、89 组工作区颜色状态、21 组平台及抽屉状态、31 项配图交互、13 项实际口播跳转链、16 组两端共享正文案例及 5 项慢上传并发回归。两轮独立对抗复核发现的问题均补测修复。升级前后 13 张数据表、141 个资料和配置文件校验一致。
