# 梯世界工作台 0.21.0

发布日期：2026-10-06。适用于 Windows 10/11 x64。

## 本版内容

- 首页采用电梯建筑背景、中央自然对话、工具分区和实际保存的图片/视频素材。
- 对话按每轮需求识别问答、定位、文案、图片或视频；创作前引导身份，允许明确跳过。
- 公众号、朋友圈、小红书、视频号、抖音各自保存成果。公众号提供标题、正文、封面和摘要；生成图片可设置为文章封面。
- 内置审阅后的公众号写作与 Humanizer 方法及 MIT 许可；统一公众号预览/导出、隐藏内部引用编号、嵌入本地图片并修正编号和字距。
- 保留此前公众号优化、图片编辑、视频生成和知识沉淀能力，以及原供应商配置和历史记录。
- 参考素材改用最长边 320 像素的缩略图，按可见范围加载；点击放大才读取原图。上传结果即时加入参考素材，素材库刷新在后台完成。
- 上传图片和粘贴图片采用等高的并排按钮，小窗口不换行或溢出；保留拖入、剪贴板与 Ctrl+V。

## 升级方式

运行 `梯世界工作台 Setup 0.21.0.exe`，安装后从“梯世界工作台”桌面快捷方式打开。应用标识保持 `com.fengsha.elevator.workbench`，个人数据继续使用 `%APPDATA%/elevator-workbench`；旧用户的数据库、加密配置、资料和作品继续保留。

本机在原安装位置 `%LOCALAPPDATA%/Programs/elevator-workbench` 升级。快捷方式指向已安装程序，不依赖项目源码目录，也不指向旧版 `win-unpacked`。

旧启动脚本优先打开当前已安装版本；后台打包包括首页背景、写作 Skills 与上游许可。
