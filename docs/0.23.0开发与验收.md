# 0.23.0：飞影数字人与清晰创作界面

首页继续沿用已有风格。行业雷达与管理后台补齐暗色面板、文字、搜索、选中、悬停及聚焦状态；正文纸张保持原有浅底深字。平台准备使用本地矢量标记，无需网络加载图标。

## 飞影入口与素材要求

| 操作 | 所需素材 |
| --- | --- |
| 创建数字人形象 | 人物视频或人物照片，二选一 |
| 文字驱动视频 | 文稿＋飞影形象＋飞影声音；或文稿＋人物视频 |
| 音频驱动视频 | 驱动音频＋飞影形象；或驱动音频＋人物视频；普通照片不能替代形象 |
| 图片驱动视频 | 人物照片＋文稿＋飞影声音 |
| 声音克隆 | 获授权的说话录音 |
| 文本配音 | 文稿＋飞影声音 |

合同依据：[飞影官方 API v2](https://api.hifly.cc/hifly.html)。详见[后端合同](飞影API-v2后端合同.md)。

服务端上传、提交、公共资源同步和状态查询在后台处理。保存本地任务和远端任务 ID；重启后恢复已提交任务查询。提交结果不确定时不再次提交，避免重复计费。公共库仅同步 kind=2 的资源，不导入同一供应商账户下的其他私有资源。旧平台配置、素材与生成历史继续保留。

IP 默认使用最新配置的用户身份，保留已有非空身份及明确选择“不使用 IP”的标记。读取身份和创作归属完成前不允许提交；工作流、对话和独立工具的草稿仍分别保存。
