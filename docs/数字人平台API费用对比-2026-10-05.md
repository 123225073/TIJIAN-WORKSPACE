# 数字人平台 API 费用对比

调研日期：2026-10-05。使用 web-access 与 research 技能，依据平台官方价格页、帮助中心和开发文档。目标是生成可下载的数字人口播视频，实时数字人通话另行计费，不混入离线视频价格。

“前10”解释为适合选型的10个代表性候选，不是有统一统计依据的市场份额或质量排名。照片动画、真人分身训练、公共数字人分别说明；聚合 API 服务与原厂身份分别标注。

费用保留原币种。$ 表示美元，¥ 表示人民币。按分钟数字是价格换算，未计税费、支付汇差、存储、额外配音、声音克隆、重做和人工后期，除非相应条目明确说明包含。套餐均注明使用量和付款周期，不能视为无限量按需单价。

## 已核对的直接按量价格

### HeyGen（原厂；公开资料存在报价差异）

官方 API 帮助页标注最后更新2026-09-16：照片数字人创建 $1.32/次，真人分身创建 $2.13/次；后者仍注明创建 API 限 Enterprise，企业合同最低消费未公开。生成费：Avatar III 照片/公共数字人 $0.99/分钟、真人分身 $0.60/分钟；Avatar IV 照片 $2.31/分钟、真人分身/公共数字人 $4.83/分钟；Avatar V 真人分身 $7.20/分钟。按实际生成秒数计费。

文字和自带音频均有API路径。单独调用 Starfish 配音接口报价 $0.12/分钟；不能据此推断每次直接脚本生成视频必然再收一笔独立配音费。按量余额有效期12个月；官方 API 营销页称 $5 起。

来源：[API帮助页](https://help.heygen.com/en/articles/10060327-heygen-api-pricing-explained)、[API套餐入口](https://www.heygen.com/api-pricing)、[音频驱动文档](https://developers.heygen.com/audio-to-video)、[数字人创建文档](https://developers.heygen.com/docs/create-avatar)。

重要限制：官方代码库的API速查资料仍出现 Avatar Video $0.10/秒（$6/分钟）等不同报价。本文表列采用有明确更新日期的帮助中心，属于公开报价参考，不能视为已验证的账号结算价。动态账户价格页本轮未成功读取；接入前应核对所选引擎、端点、分辨率的账号报价。[官方代码库](https://github.com/heygen-com/heygen-stack/blob/main/references/api-reference.md)

### WaveSpeedAI / InfiniteTalk（模型托管 API 服务）

照片+音频直接生成，不需要独立训练真人分身，因此该流程没有训练接口费用；这不等同于获得可跨姿态复用的训练分身。Fast 为 $0.015/秒，即 $0.90/分钟。Standard 480p 为 $0.03/秒，即 $1.80/分钟；720p 为 $0.06/秒，即 $3.60/分钟。输入时长向上取整到秒，最低3秒，每次最长600秒。Fast 的输出分辨率在本轮所读参数中未明确，不把它当作同分辨率对比。

该接口必须提供音频；prompt 是动作/场景提示，不能代替口播文案。文字生成视频需要先做TTS，费用另计。没有固定月费，余额不过期，最低充值因支付方式变化。平台文档称系统失败可自动退回额度，画面质量不满意不等于系统失败。[Fast价格与参数](https://wavespeed.ai/docs/docs-api/wavespeed-ai/infinitetalk-fast)、[Standard价格与参数](https://wavespeed.ai/docs/docs-api/wavespeed-ai/infinitetalk)、[计费说明](https://wavespeed.ai/docs/how-pricing-works)、[退款说明](https://wavespeed.ai/docs/refund-policy)。

模型卡明确提醒文档价格可能滞后，以实际任务结算为准；网页“$0.075 per run”“$0.15 per run”是默认/基础任务价格，不能当作一分钟视频价格。[模型卡](https://wavespeed.ai/models/wavespeed-ai/infinitetalk-fast)

## 预算核算口径

按量：总成本 = 形象创建 + 按计费粒度计算的成片时长费用 + 必须单独购买的配音/克隆/后处理 + 重做费用。

套餐：实际支出 = 套餐价格 + 超额费用 + 额外创建/配音费用。只用掉部分分钟时，真实平均单价是实际支出除以成功交付分钟数，不能沿用用满额度的最低折合单价。

质量验收后的成本：累计实际扣费 / 验收通过的视频分钟数。没有付费实测前，不能判断某平台质量最好或最终成本最低。

例：已有合适形象与音频，制作100条、每条3分钟，总共300分钟，暂不计重做和额外费用。以下只是表列单价的算术预算：

| 按量方案 | 每分钟 | 300分钟生成费 |
|---|---:|---:|
| HeyGen Avatar III 真人分身（公开帮助页参考价，账号待复核） | $0.60 | $180 |
| HeyGen Avatar III 照片（同上） | $0.99 | $297 |
| HeyGen Avatar IV 照片（同上） | $2.31 | $693 |
| HeyGen Avatar IV 真人分身（同上） | $4.83 | $1,449 |
| WaveSpeed InfiniteTalk Fast | $0.90 | $270 |
| WaveSpeed InfiniteTalk Standard 480p | $1.80 | $540 |
| WaveSpeed InfiniteTalk Standard 720p | $3.60 | $1,080 |

这些方案的模型、清晰度和动作能力不同，不能根据金额直接推断质量排名。用自带音频测生成费用，再单独比较配音，有助于控制比较条件。
