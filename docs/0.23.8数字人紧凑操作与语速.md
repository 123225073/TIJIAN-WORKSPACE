# 0.23.8 数字人紧凑操作与语速

## 操作变化

选择出镜方式后，先选数字人和声音，再输入文稿。长篇平台说明、创建说明和费用解释收进可悬停、点击的问号；提交生成时仍明确确认费用。文稿使用正常 Enter 换行，显示字数，保留草稿和所选资产。

日常表单不再展开完整视频播放器。已选素材提供预览／试听入口，“选择与预览”在当前页弹窗选择，返回无需重载原稿。形象库仅显示自己的资产，按全部／视频／照片形象分类；停止公模同步、引用、设默认，历史存储不删除。公共声音仍可使用。

## 语速实际边界

核对日期：2026-10-09；依据 [飞影官方 API v2](https://api.hifly.cc/hifly.html)。

| 用法 | 语速处理 |
| --- | --- |
| 文字＋自己的数字人＋独立声音 | 自有克隆声音可设置 0.5—2 倍；公共声音不可修改 |
| 照片＋文稿＋独立声音、文本配音 | 同上 |
| 人物视频替代形象和声音 | 官方生成接口未提供语速参数 |
| 音频驱动 | 沿用原录音节奏，生成接口未提供语速参数 |

语速是声音资产参数，不是每次生成的 options。`POST /api/v2/hifly/voice/edit` 接受 rate、volume、pitch 字符串；本程序只调整 rate 时先读取并保留音量、音调。用户点击“设置语速”后读取真实参数，点击“保存此声音语速”才修改。保存会影响之后使用该声音的创作，不修改已有成品；声音有未完成／待核查的生成任务时禁止编辑。

后端通过 `/api/studio/assets/{id}/voice-parameters` 验证归属、服务账号、状态、版本和明确确认；不自动改声音、不向生成接口发送虚构的语速字段。服务失败或重启中断时不显示假成功。
