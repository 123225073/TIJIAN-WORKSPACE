# 0.17.0 媒体创作工作区

图片与视频改为专用创作页面。保留梯见视觉风格，参考 Fengsha.chat 的实际创作面板与素材操作；参考项目仅只读检查。

| 使用问题 | 本次处理 |
| --- | --- |
| 输入和参数散落在长表单中 | 左侧模型、参考图、提示词集中排列；参数弹窗与生成按钮固定在底部 |
| 提示词优化不方便 | 一键优化、带要求优化、撤销、放大编辑；个人补充规则按图片/视频分别保存 |
| 右侧结果空泛、难以连续创作 | 顶部素材条，下面连续作品历史、真实状态与输入参数复用 |
| 选素材只能看到同名文字 | 搜索与图片缩略图选择，点击放大，拖入参考区 |
| 历史作品后续操作套用当前身份 | 使用原作品保存的品牌与身份 |

模型、参数和素材要求由真实能力目录决定。当前单参考图接口只接收一张参考图；不会摆放未接通的多图槽。实际像素仍以返回文件为准，不把请求 2K 当作实际 2K。

提示词补充规则属于当前用户的本机偏好，不替换后台系统提示词。优化要求作为用户数据传给既有文本模型；输入在等待中改变时，优化结果不会覆盖新内容。未配置视频服务时保留明确不可用状态，不展示假视频结果。
