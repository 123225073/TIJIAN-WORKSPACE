# 0.12.0：对话、成果与文章配图

本次保留原页面结构，集中修复对话结束后没有明确下一步的问题。

## 用户操作

1. 在任意工作类型下完成讨论，点击左侧 **确定工作成果**。AI 将对话整理为右侧可编辑成果。
2. 可以手动修改右侧正文。继续发送要求时，工作台先保存修改，再把当前成果交给模型参考。聊好后点击 **更新工作成果**，保留历史版本。
3. 选题、研究、对标等成果可点击 **基于此成果创作**，说明采用哪一项及文章要求。系统创建内容创作会话，自动带入成果快照、原始参考资料和身份，并开始生成。原成果保留，文章可返回查看创作依据。
4. 文章讨论完成后同样点击 **确定工作成果**。在文章中选择 **添加配图**，填写画面要求，选择已上架的生图模型和横/方/竖图，先生成预览，再选择文章开头、某个标题后或末尾，点击 **确认插入文章**。也可上传本地 PNG、JPEG、WebP。
5. 编辑或插图后，事实核查需要重新运行。Markdown、HTML 导出内嵌配图；不会自动对外发布。第三方编辑器可能不接受内嵌图片，粘贴到公众号后的图片效果仍需在平台检查。

## 成果与知识库的区别

成果是正在推进的工作文档：研究报告支持判断，选题方案指导写文章，对标分析提供写法参考，定位方案支持身份整理。它们不必先转成原始资料。知识资产用于跨任务查找、复用与长期沉淀，Wiki/记忆整理在知识资产页操作。工作区顶部的整理和删除按钮已移除。

## 管理员配置

- 每个服务下只显示自己的模型，可分别发现、测试、上架。相同模型名由服务 ID 隔离。
- DeepSeek 默认显示配置入口；已有连接保留，不重复添加。获取 [API Key](https://platform.deepseek.com/api_keys)，参考 [官方接入文档](https://api-docs.deepseek.com/)。密钥仍只由服务端加密保存。
- 生图使用服务的 OpenAI 兼容 `POST /v1/images/generations` 接口，支持 `b64_json` 或公开图片 URL 响应。参考 [Images API](https://developers.openai.com/api/reference/resources/images)。其他专有生图协议暂未适配。
- 图片模型点击“生成测试图”执行真实调用，成功后才能上架；模型发现结果本身不代表支持生图。该测试与正式生图均按服务商计费。
- 配图保存在本机数据库，预览读取经过用户认证。生成失败、取消或未确认插入时不修改文章；修改冲突要求重新选择位置。图片上限 8MB、2500 万像素。

## 验证范围

- 后端覆盖六种对话成果、编辑基准、并发修改保护、创作关联、图片访问隔离、导出和备份恢复。
- 页面流程覆盖确定成果 → 人工编辑 → 继续对话 → 更新 → 转文章 → 配图预览 → 插入，以及按服务分组、DeepSeek 入口。
- 隔离测试模型只用于测试环境，不作为真实模型效果证据。真实服务联调结果在交付说明中单独报告。
- 大规模导航与页面改版暂缓，待实际使用反馈后再确定。
