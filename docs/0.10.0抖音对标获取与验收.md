# 抖音对标作品库：0.10.0 候选版本

当前功能代码、构建和隔离流程已验证；真实网络仍出现过间歇性失败，尚不能认定为持续稳定。0.10.1修复了平台账号新增入口，桌面入口随该修复更新；抖音持续稳定性仍待验收。本候选包位于 `release/0.10.0/win-unpacked/梯见工作台.exe`，为未签名的本地桌面目录包。

## 使用流程

1. 对标研究中选择或添加抖音账号，填写完整的 `https://www.douyin.com/user/…` 主页。当前入口不支持以分享短链接直接替代主页。
2. 点击“打开抖音 / 登录验证”。软件使用本机 Chrome，未安装时尝试 Edge，并保存独立的平台会话。无需复制 Cookie，不读取平常浏览器的个人配置。
3. 点击“获取作品”，默认最多30条，可选60或100条。列表保留作品ID、发布账号、时间、发布文案和平台返回的互动数。只有发布账号标识匹配的作品才会入库，重复获取更新原记录。
4. 多选作品后下载媒体，每批最多30条。视频或图文图片保存在当前工作区 `09-附件/抖音/账号ID/作品ID/`。可在“查看文案与文件”中导出；失败项与已完成项分开记录。
5. “保存所选文案”将发布文字放入原始资料，之后可用于问答或创作。**发布文案不是视频口播，当前没有自动语音转写、字幕识别或视频理解。**
6. “订阅与通知”中开启定期检查。首轮建立基线，不通知旧作品；后续新增作品产生站内通知。可暂停，不会自动下载全部媒体，也不会对外发送消息。

电脑关机、休眠、工作台关闭或未登录时不执行订阅。每轮最多检查30条，长时间离线或密集更新可能漏项；这不是官方实时推送。遇到验证、限流或网络失败会记录原因并退避。

## 实际复用范围

- 采用 [jiji262/douyin-downloader](https://github.com/jiji262/douyin-downloader)，固定提交 `47f4eef87b34042a7862d36d9bc10f749fcb888d`，MIT许可。
- 摘取其接口参数、游标分页归一化、详情读取、登录错误分类及有限重试，存放在 `vendor/douyin_downloader`。保留许可、来源哈希和修改说明。
- Chrome/Edge仅负责平台页面会话和网络请求。采集使用固定接口，不依赖AI看屏幕、点击按钮或滚动页面。Playwright用于连接应用自己启动的独立浏览器，不使用用户常用浏览器的调试接口。
- 软件自己负责本地持久化、账号校验、批量边界、下载文件校验、取消及通知。媒体地址只暂存在主进程内存中，过期或重连后重新读取作品详情。
- 对比过 F2、Douyin_TikTok_Download_API 等方案；没有为个人工作台引入独立Redis、PostgreSQL或大型采集服务。
