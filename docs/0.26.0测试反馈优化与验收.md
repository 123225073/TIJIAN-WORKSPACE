# 0.26.0 测试反馈优化

## 本次改动

1. **首次 IP 定位**：模型将内容要求附在标题后时，不再误报缺少八段。标准标题模板与说明分开；已证实的标题格式差异做无损规范化，真正缺段、空段、重复或乱序仍拒绝。十二题回答保留。
2. **编辑与预览**：公众号、小红书、朋友圈等共用文案编辑器默认双栏；左右按滚动比例双向同步。公众号发布稿的正文编辑与排版预览同样同步，预览更新后保持当前位置。
3. **公众号配图**：一键三图先选择统一风格，内置行业插画、杂志纪实、知识图解、温暖手绘、极简商务提示词。任务自动更新，“核查任务”改为“刷新生成进度”，显示刷新反馈与图片预览。
4. **可读性**：修复公众号全篇排版设置、说明面板、生成确认及配图弹窗的明暗混杂；配对背景与文字颜色。真正的文章纸张保留浅底深字。
5. **首页**：首页组件与专属样式严格恢复 0.24.2（提交 `07c415d`），保留原标语、三个示例话题与五个直接工具入口。不是重新设计首页。
6. **选好主题**：当前 IP 的30天候选按原计划序号优先展示，默认四项，编号01–04；可展开全部。选择后默认进入公众号创作。旧候选原来源保持原样，不伪称历史报告专为公众号生成。内容区独立滚动，底部主动作不遮挡字段。
7. **小红书配图**：“生成配图”保留自定义要求与参数；“一键配图”仅选尺寸、数量、风格，默认3:4、4张、清爽知识卡片。综合完整文案先构思画面，再生成每张图，避免长文超出图片接口提示词限制。图片独立保存、可排序和下载，不插入文章；点击放大与滚轮缩放沿用已有灯箱。
8. **下一步**：多平台创作主动作改为“创作完成，下一步确认作品”，统一蓝色主按钮与箭头。
9. **首尾帧视频**：显式首帧、尾帧两张卡，各自上传、选择素材或拖入，可交换。角色独立持久化，删除首帧不将尾帧顶替。后端按角色提交，兼容旧草稿及模型能力限制。

## 验证方法与边界

使用隔离 SQLite、本地 PNG 和真实界面验证。图片、视频供应商的提交与状态测试使用明确标记的离线适配器，不把测试结果当作真实模型产出。未调用付费模型，未执行外部平台发布。定位失败采用本机失败任务只读重放；未改用户原始记录。

最终构建、测试、安装、资料保留、GitHub 附件与清理结果在本次交付记录中列出。安装器沿用当前打包方式，未数字签名。
