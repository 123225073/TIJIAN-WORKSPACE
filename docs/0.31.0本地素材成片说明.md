# 0.31.0 本地素材成片与参考调研

## 决策

素材成片采用本项目已有的 FFmpeg 本地处理基础，组合主画面、补充画面、配音、音乐、字幕和封面标题图层；不再允许创建 Shotstack 合成任务。旧任务记录与原配置保留。补充画面覆盖主画面，但不替换主画面音轨。字幕必须具有时间信息，识别结果应人工核对。

对比了 [OpenFilm](https://github.com/openfilm/openfilm)（MIT，具有多轨编辑及导出）与 [WebAV Video Editor](https://github.com/ericjay5621/webav-video-editor)（MIT，浏览器多轨编辑示例）。OpenFilm 提供参考，但完整引入其 Agent、运行环境和项目格式会扩大集成与维护范围；WebAV 项目说明中指出大视频内存和浏览器编码限制。因此本次复用现有本机 FFmpeg，参考其制作流程，不复制外部应用代码或未经授权的模板和字体。

用户提供的演示视频可见多款标题样式、素材、字幕样式及背景音乐界面；画面本身不足以证明其素材授权、每种能力的最终输出效果或识别准确率。本项目的八款封面版式由本项目绘制，使用 Windows 系统字体。独立封面 JPG 与片头 PNG 图层分开处理，默认片头标题仅显示前 3 秒，需手动避让人物。

本机可选语音识别基于 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 和 [官方转换模型](https://huggingface.co/ggerganov/whisper.cpp)，处理用户选定的本机媒体，不上传内容。模型/运行组件完成校验安装后才显示识别按钮；识别文字及时间需要校对。SRT 可直接导入。长句按真实语音停顿调整，不能仅凭字符数量捏造时间。

## 实际能力与边界

- 主画面可顺序组合图片和视频；B-roll 可指定起点、长度和裁剪区间，背景音乐和配音可调整音量。
- 导出前原素材可播放和下载，导出后成片可播放、放大、下载或加入当前作品；独立封面可选帧下载。
- 支持 9:16、16:9、1:1、4:5 和 720p、1080p；这是面向数字人口播的轻量成片工作流，不是完整的剪映多轨拖拽编辑器。
- ASR 当前针对单个主画面；多段主画面可导入或编辑 SRT。字幕每段最长 36 字，需按停顿拆分并校准时间。
- 局部替换 Shotstack 付费合成，数字人生成或第三方模型等其他功能仍按原服务和价格执行。
