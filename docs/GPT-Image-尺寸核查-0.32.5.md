# GPT Image 生图比例核查

核查日期：2026-11-05。

截图中的“3:4 → 2:3”确实来自工具自身的尺寸列表。文章配图使用 Images 接口，旧列表没有 3:4 和 4:3，工具因此在提交前就换成了最接近的 2:3，并非服务商已经拒绝了 3:4。

现已为本项目登记的 GPT Image 2 / 2.5 Images 通道补齐 15 种常用比例，并保留 2.35:1 宽银幕选项。选择 3:4 时，1K 请求使用 768 × 1024，2K 使用 1536 × 2048；4:3 使用对应横图尺寸。实际发送的是图片尺寸参数，不是只在提示词中要求比例。原有草稿的尺寸继续有效，其他模型仍使用各自原有的尺寸限制。

## 当前公开文档说明

- [OpenAI 图片生成指南](https://developers.openai.com/api/docs/guides/image-generation)：GPT Image 2，以及 GPT Image 2.5 Flare / Sunburst 的自由尺寸要求宽高为 16 的倍数、比例在 1:3 至 3:1、总像素在 655,360 至 8,294,400、单边不超过 3,840。高于 2560 × 1440 的尺寸标为实验支持。
- [OpenAI Images API 的 size 参数](https://developers.openai.com/api/reference/resources/images/methods/generate)：按具体型号列出可传的尺寸规则；GPT Image 1 等旧型号仍有更少的固定尺寸。
- [OAIREGBOX 图片接口文档](https://docs.oairegbox.cc/)：“GPT-Image 2.5 → 画幅与尺寸规格”说明 `size` 优先于画幅比例；其 `-2k` 型号列出 3:4 = 1536 × 2048、4:3 = 2048 × 1536。该平台 `-4k` 型号另有固定档位及方图限制，不能直接当作所有中转平台的通用能力。

## 本次验证范围

已用离线契约测试核对前端选择、后台校验、草稿保存恢复和最终 Images 请求一致，并覆盖原有尺寸拒绝回退行为。没有发起收费生图。

界面中的裸型号名 `gpt-image-2.5` 是当前配置的通道别名；别名本身不能证明具体服务商的能力。本次修复去除了工具错误施加的旧尺寸限制，未宣称已验证当前中转平台真实出图。服务商若明确拒绝某个尺寸，现有流程仍只在能够确认未建立任务的尺寸错误后尝试一次其明确可用的尺寸，并显示调整结果；超时或结果不明时不会因此重新付费提交。

4K 为可用尺寸档位：受总像素限制，方图最大为 2880 × 2880，不会发送不符合上述规则的 4096 × 4096。最终像素仍以服务实际返回的原图为准。
