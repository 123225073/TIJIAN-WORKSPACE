# 0.19.0 新手路径与界面实施方案

## 用户最终确认的优先路径

首页用一句话说明“问知识、找选题、做内容、整理交付”，主区域直接可提问。新用户只有一个醒目的“开始一站式创作”入口。导航按任务分层，不把创作动作、身份档案和可复用素材并列。

```text
首页（AI 对话）
一站式创作：方向 → 选题 → 内容 → 素材/成片 → 平台交付
找方向：灵感与对标、选题库
创作工具：文案、图片、AI 视频（商品口播 / 商品展示 / 门店引流 / 爆款复刻）
我的资料：个人知识库、我的 IP、出镜形象、声音资产、作品与素材
```

一站式创作页是一条可看见的连线，节点说明该步输入和产出；点节点进入专页，专页保存后有明确“返回流程/下一步”。选题不在流程页重复做表单，选题库是统一的单表，行详情用于编辑和平台交付。表格要能看到日期、选题、来源、推荐理由、交付稿标题及下一步动作；雷达、对标和人工输入都留在同库。

个人知识库只属于当前账户。后台的系统知识由管理员维护并发布，问答时按来源区分引用。首页提问走现有持续对话及知识检索；无可用文本模型时明确解释原因。长期记忆、每日对话归纳、项目记忆应分别展示开关和真实执行状态；任何尚未实现的能力不标成已运行。正式积分扣费在云端计费服务具备后启用，当前显示成本说明而不伪造扣费。

四种 AI 视频是场景入口，内部仍走已支持的文生视频或图生视频草稿。商品口播可选一张真实参考图片（商品或人物），普通图生视频不能保证准确口型；需要严格口型时进入独立数字人口播。爆款复刻要求用户提供参考视频及自己确认的结构说明；当前不自动分析参考视频，也不能把链接或文字说明冒称已分析视频。生成只显示后台已上架且接口已验证的 Seedance 2.0/2.5；配置不完整时仍允许保存草稿。

桌面布局：左侧目录有可拖动分隔线、收起/展开和双击恢复默认宽度。编辑器输入区与结果区也可调整宽度；小屏改为上下排列。持久化宽度只存在当前设备，不影响其他用户。

## 验证重点

从首页提问 → 真实会话；从灵感/人工输入 → 同一选题表 → 平台交付；流程节点进入专页并返回；系统/个人知识隔离；禁用模型不误触发生成；后台管理员可登录；窗口尺寸与拖拽/折叠；构建、相关接口测试、安装版启动与快捷方式、GitHub 提交。既有用户数据及未提交改动保留。
