# 0.23.1 行业雷达明细导航

行业雷达“关注信源”结果支持直接进入原文，工作台摘要单独保留。

- 点击资讯标题或“原文”，在浏览器打开对应文章；“查看摘要”在工作台内阅读。
- 招标来源通常只返回项目编号和公开摘要。按来源公开网页已经核对的导航规则生成对应明细链接；旧记录无须重新搜索，也不重写其原始保存数据。
- 没有可靠明细链接时，提供明确标识的来源搜索入口。畸形地址、非 HTTP(S) 地址及含账号密码的地址不生成导航入口。
- 摘要保存到知识资料时，优先保留明细来源链接，状态仍为摘要；已有保存资料不覆盖。
- 来源网站负责登录、权限和正文访问。本轮仅确认未登录时进入来源登录页面，没有验证付费正文或登录后的返回行为；如登录后停留首页，返回工作台再点一次原文。
