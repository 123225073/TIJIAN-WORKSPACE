# 梯世界：创作工作区改版与对抗审查

## 从业务目标倒推产品

电梯行业创作者要解决的是：把真实经验、选题和项目资料，变成目标客户愿意读、能够理解且可以直接编辑使用的内容。

这需要三个环节同时成立：用户表达意图足够轻松；生成内容符合身份、读者和平台；成品能持续编辑并保留。单独换一个提示词或美化页面，无法解决全部问题。

| 现象 | 原因与处理 |
|---|---|
| 文章像资料摘要，夹杂机器编号 | 旧流程偏向资料问答；新的公众号方法先明确读者问题和文章收获，再起稿和复核。内部引用从发布正文清理，来源仍保存在成果元数据与参考页。 |
| 一句话要求写文章，却仍进入知识问答 | 首页原来固定发送 `qa`。现在首页和工作区发送自然对话请求，每轮由受限 Agent 识别需求。 |
| 用户需要猜选哪个工作类型 | 去掉对话和发起工作窗口的工作类型选择器；普通问答保持对话，明确创作才生成成品。 |
| 创作没有身份与目标读者 | 创作前引导选择或建立身份，也允许用户明确跳过；普通问答不强迫定位。 |
| 聊完后还需点击确定成果，且只能保留一个稿件 | 明确的创作请求自动保存成果，每个平台独立稿件、编辑缓存与版本。后续改写不覆盖其他平台。 |
| 正文拥挤、异常字距、列表全是 1 | 预览与导出共用公众号渲染器，使用深色正文、左对齐、稳定行距段距，保留带解释段落的显式编号。 |

“爆款”应作为传播优化目标，不能作为软件对每篇文章的结果承诺。现阶段改善的是选题切入、标题与正文一致性、阅读体验、真实信息密度和平台适配；实际阅读量、获客与搜索展示需要发布后的真实数据验证。

## 已实现的使用路径

首页名称为“梯世界”，宣传语为“抢占线上曝光，用户一搜即见。”。电梯建筑概念图作背景，中部是自然对话框，随后为灵感与选题、图文、图片、AI 视频和数字人入口，再展示当前账户已保存的图片与视频素材。空素材库显示真实空状态，不冒充案例库。

在左侧交流，例如“帮我写一篇面向物业经理的公众号文章，解释电梯维保价格差异”。未选身份时先引导；选择身份继续，或明确跳过后生成。右侧“工作成果 → 公众号”包含：01 标题、02 正文、03 封面、04 摘要。正文可直接选字设置格式、插入图片、查看排版预览和导出。

继续说“改写成朋友圈文案”，右侧新增朋友圈页签。小红书、视频号、抖音分别保留稿件；视频脚本与真实生成的视频是不同成果。图片或视频请求生成本地方案，在右侧核对画面要求和模型后，通过标明“可能计费”的按钮使用已有真实生成服务，成功素材关联回当前会话。封面建议不冒充封面图片。

同平台改写以当前人工编辑后的稿件为底稿；发送下一条要求、切换平台及离开工作区前会保存当前修改。本机草稿缓存保留输入和未保存修改，版本冲突会阻止覆盖。

## 内置方法与来源

- [wechat-writing-style](https://github.com/yaoleifly/wechat-writing-style)：短段落、信息密度、标题与传播优化方法，按电梯行业适配。
- [Humanizer](https://github.com/blader/humanizer)：移除套话、机械排比、伪金句、聊天残留和装饰性格式，保持事实与文风。

原始文本、MIT 许可和 SHA256 快照保存在 `vendor/writing-skills/`。方法已加入管理后台的 Skills 库，支持既有启停与版本机制；桌面服务打包清单包括该目录。外部 Skill 不获得执行、文件操作或发布权限。

## 对抗审查

| 攻击或反例 | 处理与证据 |
|---|---|
| “公众号怎么用？”被误识别成创作 | 系统提示与服务端问句保护；测试用故意误分类的模型检查不生成成果。 |
| “请先不要写文章”仍命中“写文章” | 服务端优先拦截明确否定，测试不产生稿件。 |
| 没有身份就编造个人客户经历 | 引导定位或明确跳过；方法禁止虚构本人经历。身份方案仍使用既有审阅保存流程。 |
| 从公众号转朋友圈覆盖原稿 | 独立平台映射；后端和页面测试核对公众号人工修改仍在。 |
| 生成期间另一个窗口改稿 | 生成结束比较底稿版本，冲突时不覆盖；多个平台先全部校验再保存。 |
| 保存后马上发消息重复保存 | 页面测试发现此竞态；保存请求合并，并保留保存期间的新编辑。完整流程重跑通过。 |
| 模型要求发布、删除或调用任意接口 | 只允许有限动作与平台枚举；不支持的动作拒绝。越权编辑返回 404。 |
| 生图请求先偷偷计费 | 先存方案；页面测试确认生成按钮前无生成记录，明确点击后才提交。 |
| 源码预览正确，导出恢复旧版样式 | 公众号预览和 HTML 导出共用渲染器；旧稿中的机器编号也在导出时隐藏。 |
| 代理 DNS 异常被误报为文章采集问题 | 文本模型连接错误改为明确的模型服务网络提示；保留原有受限地址检查。没有放宽网络保护。 |
