# 0.30.2 片头与创作体验验收

## 本次修改

- 数字人片头标题默认从开头显示 3 秒，可选 5 秒、8 秒或整段。视频不足所选时长时显示到结束；字幕仍按 SRT 时间轴出现。三套模板采用不同标题样式，预览和成片按视频画面比例布局。旧成片不自动修改，可从保留的原片重新合成。
- 旧口播稿仅当名称包含明确的内部口播规则签名且本地名称未被用户另行修改时，去掉误带入的规则。修复先作为待保存修改显示，沿用原有版本检查，用户手动修改的名称不被覆盖。
- 生图历史中的完整提示词使用深色背景和浅色字；隔离 Chromium 实测对比度约 15.2:1。
- 同一次导航共享作品与草稿的权威读取，避免重复历史归属扫描；生成记录在编辑区显示后加载，加载未完成或失败时仍可编辑，但不允许提交新的生成，防止重复付费。加入作品前先同步外层待保存状态，避免旧版本竞态。
- 本地剪辑方案及 Shotstack 官方价格调研见《素材成片与本地剪辑方案分析-2026-10-28.md》。本次没有替换既有云端功能，也没有创建账号或购买服务。

## 验证

- 生产构建通过；49 项相关后端测试通过，包含真实 FFmpeg 片头时长、画面比例、字幕、音轨及源文件保留。切换与错误恢复专项 7 项、工作流后端 14 项通过；未保存文稿、已保存文稿、配图和返回编辑等界面链路通过。
- 图片工作台完整隔离回归 16 项通过；数字人三模板、预览时长、实际合成、原片与成片放大下载及一站式作品回写通过。测试未提交付费生成。
- 隔离样本中历史归属扫描每次约 267–302 ms、生成历史读取约 357–454 ms；新流程避免同次导航的重复扫描并在后台加载历史。该数字不代表用户机器的固定速度。
- 0.30.2 打包桌面启动通过，随包 FFmpeg 生成带中文字幕的测试成片，保留原片与音轨；实际安装器退出码 0。安装后从桌面快捷方式启动，六项程序和资源哈希与验收目录一致；数据库完整性正常，13 张表记录数量与升级前一致。升级前数据库备份保存在 `.runtime/upgrade-0.30.2/`。
- 真实飞影视频、真实付费模型、第三方云端渲染和正式发布未在本轮验证。自动字幕识别、本地时间线剪辑器和自动发布不属于本次已实现功能。
