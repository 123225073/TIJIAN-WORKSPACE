# 0.15.0 访谈建档与功能闭环

本次针对用户反馈修正实际调用链，前台与独立管理后台同步更新。

## 使用方式

- 品牌与 IP → AI 访谈建档：AI 主动提问，用户回答；点击「没有更多信息了 · 结束并整理」，编辑结果后确认入档。现有档案可选择「AI 补充资料」。访谈保存在数据库；未发送回答暂存在当前设备。手动编辑保留。
- 后台 → 功能模型绑定 → AI 生图：选择已验证上架的 `gpt-image-2.5`，保存。用户现有 CPA 连接和密钥无需重填。本次不擅自改动已安装版本的配置。
- 图片修改、视频、数字人各模式、配音、声音/形象创建、视频合成分别绑定对应媒体 API；图片模型不能绑定到口播或视频接口。停用绑定后前台禁止生成，仍可编辑草稿。
- 一站式创作：选择品牌、身份、主题及已有成果，点击功能节点创建独立草稿。文稿带入文字口播或配音；选择画面和音频后可带入合成场景，时长等参数仍需在工具页核对。跳转不触发付费生成。

## 修正与整理

- 草稿保存、状态轮询、主题自动保存不再发出全局“已完成”通知；单纯打开工具不再创建空白数据库草稿。
- 切换图片服务时，旧草稿不兼容的参数恢复为新服务默认值并给出提示，CPA Images 接口不显示百炼专属水印参数。
- 前台能力目录、后台服务绑定和生成端校验保持一致。兼容 Images 的生成结果纳入统一任务和本地素材库；同一请求不会重复生成，未知提交不会自动重试。
- 当前提示词与 Skills 入口只保留文案、身份访谈、品牌访谈、对标分析及通用方法。移除旧日常沟通、知识整理、资料研究、独立选题策划的配置入口。历史数据和兼容代码保留，不批量删除用户资料。
- 档案整理只根据用户提供信息，不自动沉淀知识库。AI 结果不会直接覆盖档案；原档案版本变化时阻止更新。
