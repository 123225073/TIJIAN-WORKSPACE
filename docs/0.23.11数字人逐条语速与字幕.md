# 0.23.11 数字人逐条语速与字幕

## 已确认的原因

真实自有基础版声音的接口响应将 rate、volume、pitch 返回为空字符串；原工作台直接校验空字符串，报“声音参数无效：rate”。现在按官方文档的未设置默认值 1.0 解释，仅兼容空值，仍拒绝非空的非法参数。复查实际账号的声音读取已通过，未编辑飞影声音或提交新生成任务。

文字驱动原任务只保存了 `st_show: 1`，因此平台沿用较大的默认字号、宽度与固定左侧坐标；原视频实际为 1080×1906、37.6 秒。品牌水印来自平台返回的成片：原任务响应仅提供 `video_Url`，没有另一份无水印成片地址。

## 本条视频的语速

文字驱动、音频驱动与图片驱动均提供独立的“本条语速”，范围 0.5—2 倍、步长 0.05，常用 1.1 和 1.2 倍可直接点击；随草稿和提交快照保存。不同视频互不影响，切换语速不修改声音资产或重新克隆。

飞影生成接口没有已公开的单次语速参数。本实现保留原生成任务：返回成片后用本机 FFmpeg 同步处理声音与画面的时间轴，保持音调并保存可播放、可下载的实际文件。原成片保留；这不是播放器倍速，也不增加飞影生成次数。倍数相对于飞影返回的原成片；本地处理需要重新编码，采用 H.264 CRF 18 和 AAC 192 kbps。平台费用仍以原生成任务账单为准，本地加速不改变已提交的任务。

缺少本机处理组件时，在提交付费任务前提示修复安装。成片处理失败保留原任务与原结果，核查原任务只重试结果保存，不重新付费生成。后台只发送官方字段，`video_rate` 不发送给飞影，也不调用 `voice/edit`。

## 字幕和水印

字幕默认关闭。需要时开启，默认按原素材画布使用底部居中、适合画幅的较小字号、白字与深色描边。可展开“字幕样式”选择位置和小／标准／大字号。修改用于后续生成；已烧录的旧字幕不能直接移动。

“飞影数字人”品牌水印与“AI 生成”标识是不同项目。公开 API 的 `aigc_flag` 仅描述 AIGC 标识，不承诺去除平台品牌水印；现有公开接口没有品牌水印关闭参数。平台权益说明也将生成积分与去水印权益分开。当前 API 账号是否具备无品牌水印输出权限，需向飞影核实；本次不购买权益、不承诺自动去除品牌水印。

来源：[飞影官方 API V2](https://api.hifly.cc/hifly.html)、[官方会员权益说明](https://hifly.cc/study/feature/member/DRzidPlCToAjiIxq9KccHleLn7r.html)。会员说明发表于 2024 年，仅用于确认权益分项，不将其中网页端价格套用于当前 API 账号。
