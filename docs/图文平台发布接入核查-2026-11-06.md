# 图文平台发布接入核查

核查日期：2026-11-06。范围：内容矩阵中 8 个图文平台。未登录平台账号，未申请权限，未提交真实文章，未调用收费服务。

## 结论与产品修正

当前源码只有**公众号和 WordPress 官网**的原生发文适配。其余 6 个平台使用的是用户自备、且需要兼容本工作台协议的 HTTPS 发布服务；过去统一展示「发布地址 + 访问令牌」容易被理解为已经完成这些平台的官方接入，这是不准确的。

本次已把账号设置改为「平台实际发布方式 → 官方入口 → 可选高级服务配置」。没有自备服务时，直接指向官方后台；不再让普通用户寻找平台根本不提供的“通用令牌”。新官网连接默认使用 WordPress，已有服务地址、启停和凭据保留。发布预览也会区分“WordPress 官网”和“自定义发布服务”，后者的成功文字表述为服务回执，不冒充平台回执。

## 参数与长期授权不能混用

- **WordPress**：自家网站地址 → 网站用户 → 应用程序密码。每个用户的域名与权限不同，禁止填写别人的官网或登录密码。
- **公众号**：同一公众号 AppID/AppSecret → 出口 IP/账号权限 → 草稿与发布接口。保存凭据不会自动公开文章。
- **平台自身同步权益**：在头条或搜狐后台申请、管理，不能被本工具保存两个文本框替代。
- **第三方发布服务**：必须由服务商提供适配本工具的服务地址和配套令牌，并已经在该服务授权目标平台账号。任意第三方 API 文档中的端点并不一定兼容；当前版本没有自动适配各家服务，也没有接入全平台网页登录或 Cookie 托管。

工作台会加密保留已保存的连接直到用户更新、撤销或凭据失效。服务商、平台和网站管理员可以随时撤销或改变权限，因此“永久登录”不能作为功能承诺。
