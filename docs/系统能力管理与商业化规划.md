# 系统能力管理与商业化规划

适用版本：0.7.0。本文将已经交付的本地能力和未来商业化工作分开说明。

## 管理员现在在哪里修改

打开 **设置中心 → 系统能力 · 管理员**。

- **系统提示词**：编辑内容创作、资料研究、对标分析、选题策划、定位访谈、事实核查、知识整理七种角色。点击“保存并启用”后，下一次对应 AI 请求使用新版本。
- **Skills 方法库**：添加、编辑、指定适用功能、保存为未启用草稿、启用、停用、删除；支持恢复历史版本和内置默认。内置 Easel 原始文件及许可保留，修改作为应用配置保存。
- **已删除**：删除的方法立即退出后续请求，从正常列表移走；历史版本保留，可恢复。这里是可恢复删除，不是销毁数据库。
- **预览生效提示词**：查看已保存的系统规则、角色、适用方法和当前管理员个人偏好。不调用模型，不产生模型费用。未保存的编辑不会出现在预览中；预览也不包含会话资料和历史消息。
- **模型连接、功能绑定与用户管理**：从同页链接进入已有管理后台，配置服务、验证和上架模型，绑定各功能的默认模型。

例如，要优化定位访谈：选择“系统提示词 → 定位访谈”，写明角色、访谈目标、每轮问题数量与结果格式，保存并启用，再回到原会话发送新消息。旧回答不会被重写。模型是否严格遵守指引还需要真实模型验收，设置生效不等于质量保证。

**两个选择器的含义不同**：工作类型决定 AI 做什么、使用什么角色和方法；运营身份选择的是用户已经维护的个人定位、受众和表达习惯，不是另一个 AI 角色。模型选择则决定谁执行这些指引。

普通用户只看到 **AI 与创作偏好**，可以设置自己的篇幅、语气等偏好。管理员的提示词和 Skill 正文不会通过普通用户配置 API 返回；后台读写、预览和恢复接口均校验管理员身份。

## 当前系统如何组织一次请求

1. 程序保留的基础规则：事实依据、来源标记、外部内容边界、不能虚构工具执行。
2. 管理员配置的业务角色：所选工作类型对应的系统提示词。
3. 已发布且适用该功能的 Skills，以及已上架的行业参考资源。
4. 当前用户自己的工作偏好。
5. 运营身份、已确认记忆、选中资料及匹配的已确认知识。
6. 会话历史和本轮用户要求。

事实核查与知识提炼还保留程序要求的 JSON 结果结构。定位访谈等五类会话、事实核查和知识提炼都已接入管理员配置。维护摘要等内部辅助请求并不属于这七类业务入口，仍使用程序内置指引。

配置在任务提交时固定；管理员随后修改配置，只影响后续提交。任务记录保存功能、配置项 ID、版本、摘要校验值与时间，不把内部提示词正文写进普通用户任务日志。历史版本和管理员审计保存在服务端。并发编辑使用版本校验，旧窗口不能静默覆盖新配置。

当前 Skills 是**文本方法**，适用于访谈、研究、写作、风格等。新增 Skill 不会安装依赖、执行 Python、运行 shell、开放文件系统或自动发布内容。若未来支持可执行 Skill，必须单独引入工具注册、权限声明、沙箱、网络和成本限制，不能仅靠提示词控制。

## 本地版与商业版的职责划分

| 配置/数据 | 当前本地版 | 商业版应由谁控制 |
|---|---|---|
| 系统角色、内置方法与功能目录 | 本机管理员，服务端全局配置 | 平台管理员；按发布版本分发 |
| 模型连接、密钥、功能默认模型 | 本机管理员；服务端加密密钥 | 平台管理员；租户可授权选择服务 |
| 组织自己的方法、知识与预算 | 暂无独立组织租户层 | 组织管理员；限制在自己的租户 |
| 个人定位、语气、选用模型 | 当前用户 | 当前用户，在产品允许范围内 |
| 对话、文稿、私有来源和记忆 | 按用户隔离 | 按租户和用户双重隔离 |
| 基础工具权限、数据访问边界 | 程序控制 | 服务端权限系统与执行沙箱 |

本版新增的 `backend/capabilities.py` 集中处理角色、方法、版本和请求配置快照，页面不直接拼装系统提示词。管理员 API 与个人偏好 API 分离，便于后续迁移管理界面与配置存储。已有本地注册登录并不等于商业账号系统。

## 商业化实施顺序（规划，尚未部署）

1. **租户与权限**：引入平台管理员、组织管理员、成员角色；所有业务对象、检索索引、缓存和后台任务强制附带租户/用户范围。禁止使用客户端提供的角色授予权限。增加完整鉴权和越权测试。
2. **配置发布**：把角色、Skills、工具权限、模型路由组织为版本化发布包。分别保存编辑草稿与线上版本，支持预览、审批、灰度、回滚和变更审计。当前“保存为未启用草稿”会停用这一方法，并非商业版的双版本发布机制。
3. **执行与费用**：集中管理密钥、调用限额、超时、取消、用量账本和请求幂等；付费整批确认继续保留。可执行 Skills 只能运行在受控沙箱，权限不得来自上传的文档或模型输出。
4. **数据和检索**：保留业务库，建立可替换的检索服务接口；返回资料 ID、片段、来源位置、版本与权限范围。外部知识服务不可替代本地知识的确认、冲突与失效规则。
5. **云端运营**：补齐注册邀请、登录恢复、配额/订阅、部署备份、监控、升级与故障恢复。使用自己的真实文档做质量与成本评估后再开放服务。

系统能力目前存储在本地服务 SQLite 的 `system_capabilities` 配置中。普通用户资料导出不会携带全局管理员配置。商业迁移需要专门的管理员配置导出/导入与密钥迁移方案；不能把用户资料备份当作完整服务备份。

## 本版验证边界

后端检查管理员权限、版本冲突、删除与恢复、实际模型请求中的角色和方法注入，以及提交时固定版本。桌面隔离流程检查编辑后发送任务、免费预览、键盘选择、空白关闭和小窗口布局。使用的是测试模型替身，未使用真实用户模型密钥，未产生真实调用费用；没有部署商业云服务。
