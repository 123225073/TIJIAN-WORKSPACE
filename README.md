# 梯世界 · 电梯行业 AI 内容工作台

**当前源码版本：0.32.2 · 内容矩阵五步创作。** 面向电梯行业与合作方的本机桌面工作台，支持选题、文章、图片、AI 视频、数字人、配音和视频剪辑。Windows 安装附件和对应校验文件以仓库 Releases 的实际发布内容为准。

## 内容矩阵：从选题到发布

内容矩阵的五个步骤位于左侧目录，随时可以返回修改。每件作品、每个平台文稿独立保存，切换页面保留本机草稿；对外发布使用已经保存的指定版本。

1. **IP 与选题**：选择表达身份，查看该 IP 的推荐选题，也可输入自己的主题或从选题库选择。身份、推荐选题和本次主题采用相同层级的章节标题。
2. **内容母版**：按主题生成一篇完整行业文章，流式正文直接显示在同一个文章区，完成后自动保存；可直接阅读、编辑和重新生成。写作采用后台已启用的写作角色与 Skills，强调明确观点、通俗解释、适用条件和可核对的事实。资料不足时仍需用户核对，不能把模型输出当作已经核实的结论。未保存正文优先从本机恢复，遇到外部更新时保留两份供选择。
3. **选择平台**：单独勾选官网、微信公众号、小红书、知乎、百家号、今日头条、简书或搜狐号，查看各平台的内容特点和建议篇幅。
4. **平台创作**：引用同一份已保存母版，按各平台读者和表达方式分别生成文稿。平台标签切换后直接阅读、编辑，不需要展开其他工具；公众号支持浅底深字的排版编辑和最终预览。每个平台文稿下方都可单独提交发布。
5. **发布与账号**：逐个平台核对文稿版本、账号、目的地及状态，也可一次提交全部已经就绪的平台。账号管理与发布作品分开显示。

模型生成需配置可用服务，并可能按供应商计费。保存、导出及切换步骤不会触发外部发布；单独发布和批量发布均需用户明确点击并核对确认。

## 发布能力与账号配置

- **微信公众号**：使用微信提供的 AppID/AppSecret 接口，自动准备当前版本的发布稿、上传图片、同步草稿并提交公开发布。封面和可用账号齐备后才能提交；微信受理任务不等于最终发布成功，发布页会查询已有任务并展示最终回执。还需要账号具备相应权限，并配置正确的 API IP 白名单。
- **WordPress 官网**：在账号管理中填写各用户自己的网站地址、用户名和应用程序密码，通过 WordPress REST API 上传图片并发布文章。
- **其他官网及图文平台**：使用用户已经授权的 HTTPS 发布服务接口和访问令牌。工作台提供文稿、排版 HTML、附件和去重标识；平台登录、权限及实际发布由对应服务负责。这里不是小红书、知乎等平台的原生浏览器登录适配器，需要先具备实际可用的发布服务。
- 凭据在本机服务端加密保存，升级不主动清除配置。平台会话与令牌是否失效取决于平台规则，不能保证永久登录。对于结果不明的提交，保留记录并核查原任务，不自动重新发送。

当前仍是本机桌面应用，尚未部署多经销商商业云服务。接口契约测试、本机界面测试和真实账号联调是不同的验证范围；本版本未通过测试模拟结果宣称真实模型质量、公众号权限或其他平台发布已经验收。

## 视频与对标

AI 视频前台固定使用 OAIRegbox 的 **MiniMax H3 Pro · 2K**，默认首帧生视频、9:16；生成参数和参考素材在左侧，素材库与视频作品在右侧。管理后台保留四个 H3 型号的配置、官网和接口资料；前台无需选择模型。参考素材限制在执行前检查，原有平台配置与历史作品保留。

链接对标支持在当前页提取文章正文或视频文案、保留原始文本、进行 AI 校正，再带入二次创作。受原站登录、验证、可访问内容及本机转写能力限制；无法取得原文时会显示失败，不伪造原始文案。需要登录或验证时仍可能要求用户完成操作。

视频剪辑支持从素材库选用或上传外部画面与背景音乐，并通过轨道和数值字段调整素材起点、使用片段和时长；真实媒体的兼容性需以预览及最终导出结果为准。

## 公众号：优先免费，付费手动选择

1. 添加对标公众号，提供该账号发布的一篇文章。
2. **免费正文采集**：使用桌面浏览器读取公开原文；遇到平台验证，弹出窗口由用户操作。
3. **免费订阅**：在微信读书窗口登录、保存连接，定期检查并保存新文章；首次建立基线，不提醒旧文。
4. **次幂备用**：手动选择账号识别、历史目录或正文补采。每次付费操作确认费用，一批多篇只确认一次整批费用。
5. 已保存正文可本地阅读、筛选与导出，不再调用次幂。

免费订阅依赖微信读书的登录和收录能力，是定时检查而非官方实时推送。列表降级时可能只能获取最新一篇；工作台退出或电脑休眠时暂停。免费失败不会自动转为付费。详情见[采集与费用说明](docs/公众号采集与费用.md)。

## 快速开始（Windows PowerShell）

准备 Git、Node.js 22 LTS（建议 22.12 或更高）和 Python 3.12，然后执行：

```powershell
git clone https://github.com/123225073/TIJIAN-WORKSPACE.git
cd TIJIAN-WORKSPACE
npm ci
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm run build
npm run desktop
```

首次创建本机账户、选择专用空目录作为工作区。需要 AI 时，通过左下角账户菜单进入管理后台，配置自己的模型服务。详细步骤见[安装与运行](docs/安装与运行.md)。

```powershell
npm test          # 隔离后端测试，不使用正式账号凭据
npm run package  # 构建 Windows 目录包
```

0.32.2 Windows 本地安装包的预期路径为 `release/0.32.2/TISHIJIE-Setup-0.32.2.exe`，同目录提供 `SHA256SUMS.txt`。安装附件是否已上架以对应 GitHub Release 为准。旧版用户在原位置升级，账号配置、历史资料和作品继续保留。

## 技术与数据

- 界面：React 19、TypeScript、Vite、Lucide 图标。
- 桌面：Electron 39，隔离的网页会话、主进程桥接和本机服务。
- 后端：Python、FastAPI、SQLite、Markdown，PyInstaller 打包。
- AI：支持 OpenAI 兼容的 Chat Completions / Responses 服务，实际兼容性需逐模型测试。
- 用户资料在本地保存；模型调用会把所选上下文发送给配置的模型服务。公众号服务会收到本次请求所需的文章或账号标识。
- 模型密钥、公众号 AppSecret、次幂凭据和保存的微信读书会话在本机加密保管，不进入工作区备份或 Git 仓库。加密文件和密钥同属本机安全边界，不能替代操作系统账户保护。

仓库排除了运行数据库、工作区、浏览器会话、密钥、缓存、依赖目录、测试产物和安装包。本地个人联调脚本及历史验收资料也未上传。

## 已知限制

- 公众号和微信读书接口受平台变化、收录、登录及访问限制影响；不能保证全历史、实时性或账号零风险。
- 公众号正文导出为文本 Markdown；不是完整图片离线包或 PDF 归档。
- 抖音作品获取与下载已实现，真实网络与账号下的持续稳定性仍待验收。视频号等受限页面不能保证自动提取字幕；云端常驻订阅尚未交付。除微信公众号和 WordPress 外，图文自动发布需连接用户自行提供的已授权发布服务。
- 公众号草稿与公开发布接口已完成隔离测试，尚未用真实公众号账号、权限和 IP 白名单进行联调；微信受理发布任务不等于最终发布成功，须查询状态。保存或导出文稿不会自动发布。
- 本次源码发布不新增项目整体开源许可。第三方文件遵守其原有许可证，详见[来源与许可](THIRD_PARTY_NOTICES.md)。

## 历史兼容：官方 Seedance 视频配置

以下是后台仍保留的官方方舟适配说明；本版 AI 视频前台固定使用 MiniMax H3 Pro · 2K，不采用这里的模型选择流程。

1. 管理后台 → 媒体平台与模型 → 火山引擎·方舟，填写官方 API Key。控制台开通相应 Seedance 模型后，在 AI 视频中选择模型；官方模型 ID 或自己的推理接入点 ID 均可配置。
2. 文字、图片、音频参考可直接使用；本地视频参考需要在同一个平台设置里配置火山 TOS 的桶、地域和访问密钥。素材保持私有，后台上传后签发临时地址。也可直接填公开 HTTPS 地址或官方 `asset://` 素材 ID。
3. 创作页选择文字、多素材参考、首帧、首尾帧、视频编辑或延长，再设清晰度、比例、时长等。选项随版本变化：2.5 最高 1080p、最长 30 秒；2.0 标准版另支持 4K；Fast/Mini 最高 720p。
4. 2.5 支持 480p 样片，满意后用原样片任务生成正式视频。样片与正式视频分别计费。尾帧可用于连续镜头；正式生成需再次确认。
5. 任务取得官方编号后，后台持续查询并保存到本地。接口响应不明时仅核查原任务，不会自动再次生成；已排队的官方任务可取消。原平台下架不删除历史素材或加密配置，后台仍可重新上架。

官方依据：[视频生成 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[Seedance 2.5 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)。参考真人肖像需遵循官方授权素材流程。1080p/4K/MOV 的编码可能需要兼容播放器，工具保留原文件下载。

验证边界：接口契约及界面使用隔离测试账号与测试响应，不代表真实模型质量、账号权限或账单已验证。真实调用请在后台配置官方账号后进行，密钥不要填在聊天、代码或日志中。
